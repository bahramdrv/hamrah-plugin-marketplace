# کارنامهٔ مقدماتی تحصیل بریتانیا — تیکت ۰۴

سیاست `uk-student-guidance-1`، بررسی منابع در ۱۷ اکتبر ۲۰۲۶. قرارداد، Self-service Guidance Report در CONTEXT و ADR-0010 است؛ ADR-0005 حفظ می‌شود. دادهٔ متقاضی خوداظهاری است؛ هیچ مدرک، PASS/FAIL رسمی یا احتمال ویزا تأیید نمی‌شود.

## دامنه و منابع اولیه

شناسهٔ مستقل `uk:student`؛ متقاضی اصلی ایرانی از ایران، entry clearance برای دورهٔ تمام‌وقت دانشگاهی. سن دقیق، هدف، مقطع، پذیرش و بودجه از فرم خوانده می‌شوند؛ اطلاعات اختصاصی CAS، دوره و روش اثبات زبان/مالی در ادامهٔ همان پرسش‌نامه، یک سؤال در هر مرحله، خوداظهاری و ذخیره می‌شوند. صفحهٔ کارنامه ورودی مستقلی ندارد. شماره و تصویر مدرک دریافت نمی‌شود. CAS با پذیرش یکی نیست.

## نتیجه، تازگی و عددها

تابعیت دوگانه، درخواست داخل بریتانیا، دورهٔ دیگر، سن ۱۶–۱۷ و سابقهٔ خاص تحصیل/حمایت دولتی بریتانیا نیازمند بررسی مستقل‌اند؛ این برچسب رد مسیر نیست. اصالت و پذیرش مدارک، Genuine Student، Part Suitability، مجوز اسپانسر/دوره/محل و مؤسسهٔ مالی احراز نمی‌شوند. پوشش همیشه جزئی است؛ حتی سازگاری تمام موارد بررسی‌شده به معنی آماده‌بودن برای ارسال نیست. IRVI، Practical Fit، امتیاز Immi یا نمرهٔ مخلوط ساخته نمی‌شود؛ score=null.

هر منبع URL، شناسه، checked_at، expires_at و effective_from دارد. تاریخ مؤثر جدول هزینه معلوم است؛ آغاز حقوقیِ نسخهٔ سایر صفحات احراز نشده و null است. checked_at جای تاریخ مؤثر نیست. کاربرد فقط برنامه‌ریزی جاری است؛ تاریخ هدف قبل از بررسی یا از روز انقضا به بعد needs_review می‌شود. مهلت بررسی هفت روز است، نه وعدهٔ ثابت‌ماندن قانون. تغییر شناخته‌شدهٔ مؤثر باید سیاست تازه بسازد.

منبع منقضی یا آینده، ساخت تطبیق سازگار تازه و اعداد عمومی را متوقف می‌کند. گزارش قبلی ثابت می‌ماند؛ wrapper خواندن، خارج snapshot، تازگی و نسخهٔ سیاست، آخرین نسخه و revision پاسخ‌های فعلی را می‌سنجد. تعارض فعال فرم، CAS در کنار «پذیرش ندارم»، یا پرداخت شهریه بیشتر از شهریه نیازمند بازبینی‌اند. شرط نامحقق با نمره یا بودجهٔ بالاتر جبران نمی‌شود.

تمکن از هزینهٔ مصرفی جداست. ارز غیر GBP بدون نرخ معتبر تطبیق نمی‌گیرد؛ تبدیل ثابتی وجود ندارد. صفر فقط پاسخ صریح صفر است. کسر اقامت از هزینهٔ زندگی بیشتر نمی‌شود. هزینهٔ مرکز، ترجمه، سفر، کل IHS و جمع مصرفی نامعلوم می‌مانند. وام/حمایت/معافیت محاسبهٔ احرازشدهٔ نقدی نمی‌گیرند. مبالغ شهریه/پرداخت GBP حداکثر دو رقم اعشار دارند.

## ذخیره و API

POST `/api/account/report`: فقط expected_revision و request_id؛ facts یا پاسخ تازه پذیرفته نمی‌شود. owner، سیاست، ساعت و پاسخ‌ها را سرور از همان پرونده تعیین می‌کند. snapshot دارای route_results است؛ هر ماژول نتیجهٔ خود را به همان کارنامه می‌دهد و فعلاً فقط uk:student پیاده شده است. اطلاعات عمومی پاسپورت و شمار همراه هویت مشترک دارند؛ سؤال‌های اختصاصی با uk_student_ مشخص‌اند و با هدف تحصیل و مقصد uk یا بدون ترجیح مرتبط می‌شوند. مقصدهای دیگر پاسخ بریتانیا نمی‌گیرند؛ نبود ماژول با نبود پوشش توضیح داده می‌شود. GET همان مسیر آخرین snapshot و GET `/api/account/report/:id` فقط نسخهٔ همان مالک را می‌دهند. پاسخ‌ها no-store و Vary: Cookie؛ نوشتن نیازمند origin است.

مهاجرت `003-reports.sql` فقط روی دیتابیس آزمایشی اعمال شده است. RLS اجباری، نقش محدود و تراکنش مالک، revision و گزارش را محافظت می‌کنند. snapshot شامل تمام پاسخ‌های همان پرونده و provenance آن‌هاست؛ هر route_result نیز facts استخراج‌شده، سیاست و منابع مصرف‌شده، SHA-256 و نسخه دارد. نقش اپ UPDATE گزارش ندارد. retry هم‌زمان یک snapshot می‌سازد؛ بدنهٔ متفاوت برای همان ID تعارض می‌دهد. گزارش قدیمی تغییر نمی‌کند و با revision/نسخهٔ تازه جاری محسوب نمی‌شود.

سقف هر پرونده ۱۰۰ snapshot است؛ سقف، خواندن نسخهٔ موجود را قطع نمی‌کند. ساخت تازه فعالیت و تمدید ۹۰روزه است؛ retry و خواندن تمدید نمی‌کنند. حذف/انقضای پرونده با CASCADE گزارش‌ها را پاک می‌کند. export حساب شامل آن‌هاست. UI تاریخچه و چاپ حرفه‌ای متعلق به تیکت ۰۷ است.

آزمون قطعی از API عمومی گردش‌کار و Auth/PostgreSQL واقعی محلی می‌گذرد؛ داده ساختگی و ساعت قابل کنترل است. سایت دولتی زنده و مدل وارد آزمون نمی‌شوند. کامل، ناقص، کمبود وجه، ارز دیگر، تعارض، انقضا، مرز شش‌ماهه/۲۸/۳۱ روز، همراه، retry، مالکیت، export و حذف پوشش دارند.

## تاریخچه و چاپ — تیکت ۰۷

در «حساب من»، فهرست نسخه‌ها با تاریخ تهران، نسخهٔ پاسخ‌ها، پوشش جزئی، دلیل ساخت نسخه و وضعیت نیازمند بازبینی نمایش داده می‌شود. `GET /api/account/reports` خلاصه‌ها را به ترتیب جدیدترین می‌دهد؛ snapshot پاسخ‌های خصوصی را برای ساخت فهرست ارسال نمی‌کند. `/report?id=<uuid>` همان نسخه را می‌خواند؛ اصلاح پاسخ‌ها از همان فرم و ساخت صریح گزارش تازه انجام می‌شود.

علت ساخت نسخه نسبت به نسخهٔ قبلی، «نخستین»، «تغییر پاسخ»، «تغییر نسخهٔ شواهد/قواعد» یا «ساخت دوباره» است؛ هر دو تغییر هم‌زمان قابل نمایش‌اند. وضعیت فعلی جدا از snapshot و با revision جاری، نسخهٔ شواهد، تازگی منابع و آخرین گزارش محاسبه می‌شود. به‌روزرسانی رسمی منبع در تیکت ۰۸ است؛ مشاهدهٔ تاریخچه یا چاپ، منبع را دریافت یا تاریخ تأیید آن را تمدید نمی‌کند.

`GET /api/account/report/<uuid>/print` پس از احراز نشست و مالکیت، HTML مستقل فارسی و RTL می‌دهد. قلم Vazirmatn محلی، اندازهٔ A4، منابع و نشانی خوانا، جزئیات باز و شکست صفحهٔ بخش‌ها دارد. دکمهٔ چاپ پس از آماده‌شدن قلم، چاپ/PDF خود مرورگر را اجرا می‌کند؛ سرویس PDF یا inference وجود ندارد. داده، مبلغ نامعلوم و منابع همان snapshot نمایش داده می‌شوند؛ هشدار قدمت بیرون از snapshot است. پاسخ چاپ no-store و Vary: Cookie است؛ نشست دیگر/نشست بازیابی/نشست نامعتبر مجوز خواندن گزارش نمی‌گیرد. خروج در تب دیگر نمای چاپِ باز را پاک می‌کند؛ بازگشت از کش مرورگر صفحه را تازه دریافت می‌کند.

ساخت HTML از renderer معمول Node در `print.tsx` استفاده می‌کند؛ API route یک سند مستقل می‌دهد و وارد renderer مربوط به React Server Components نمی‌شود. صفحات تعاملی و چاپ، نمایش گزارش را از `SavedReport` مشترک می‌خوانند.

### پذیرش محلی ۲۱ اکتبر ۲۰۲۶

- ۱۰۰ تست اپ با Auth/PostgreSQL محلی و دادهٔ مصنوعی گذشت؛ تست‌های گزارش شامل دو مالک، نشست نامعتبر، نسخهٔ مشخص، چاپ، عدم تغییر snapshot، تغییر مستقل شواهد، تغییر پاسخ و ساخت مجدد هستند. به دلیل اجرای مکرر، شمارندهٔ global محیط تست پیش از اجرای تمیز بازنشانی شد؛ سقف runtime تغییر نکرد.
- ۳۸۴ تست مخزن، verify:release، check:static و ۴۷ تست Python گذشتند. build و typecheck اپ موفق‌اند؛ Python پیش‌فرض pytest نداشت و همان تست با `uv run --offline --with pytest python -m pytest ...` اجرا شد.
- مرورگر Chromium روی build محلی: تاریخچهٔ دو نسخه، دسترسی مستقیم به نسخهٔ قدیمی، هشدار تغییر پاسخ، دسکتاپ ۱۲۸۰، موبایل ۳۹۰، بازچینی viewport معادل بزرگ‌نمایی ۲۰۰٪، Enter روی لینک تاریخچه و دکمهٔ چاپ آزموده شد. RTL، قلم آماده و بازبودن تمام جزئیات تأیید شدند. HTML چاپ واقعی از endpoint خصوصی با ۲۰۰ دریافت و PDF با اندازهٔ A4 ساخته و صفحهٔ اول آن دیداری بررسی شد.
- شواهد مصنوعی: `.scratch/kooch-self-service-app/evidence/history-{desktop,mobile,zoom}.png` و `history-print.pdf`. چاپگر فیزیکی و انتشار production جزو این پذیرش نیستند.
- بازبینی Spec یافته‌ای نداشت؛ Standards یک اختلاف منطقهٔ زمانی یافت که با ثابت‌کردن تاریخ‌های نما به Asia/Tehran رفع شد.
