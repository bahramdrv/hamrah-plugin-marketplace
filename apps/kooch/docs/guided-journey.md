# مصاحبه و کارنامهٔ پیوسته — ۲۴ اکتبر ۲۰۲۶

مرجع خواسته و پذیرش: `.scratch/kooch-guided-journey/spec.md`. نسخهٔ جدید، هدف و مقصد را می‌پرسد، پیش‌نیازهای مرتبط را زودتر مطرح می‌کند و سپس جزئیات مرتبط همان هدف را می‌گیرد. فهرست سؤال‌ها و پیشرفت از API می‌آید؛ تعداد نهایی ثابت ادعا نمی‌شود. آرایهٔ `answered` پاسخ صریح نامعلوم/بدون ترجیح را از مقدار پیش‌فرض جدا می‌کند؛ دادهٔ قدیمی با آرایهٔ خالی خوانده می‌شود.

ویرایش پاسخ، فقط فیلد تغییرکرده و بستار وابستگی‌های واقعی را بازبینی می‌کند. تغییر نشانگرهای مصاحبه، سن دقیق یا مدرک زبان مستقل را باطل نمی‌کند. تغییر دامنهٔ مقصد، سؤال‌های اختصاصی همان کشور را نیازمند بازبینی می‌کند. پاسخ‌های مرتبط با هدف دیگر برای سابقه می‌مانند و مصرف نمی‌شوند.

## خلاصهٔ ذخیره‌شده

تمام هدف‌های دارای شواهد می‌توانند خلاصهٔ کشف مسیرها و قدم بعدی را در همان کارنامهٔ خصوصی ذخیره کنند. این بخش، ارزیابی رسمی شرایط فردی نیست. ماژول‌های بررسی تکمیلیِ موجود برای UK/CA study همان مرز و منبع قبلی را دارند. گزارش‌های قدیمی که فیلد `discovery` ندارند همچنان خوانده می‌شوند.

خلاصه از snapshot عمومیِ قابل مصرف همان محیط ساخته می‌شود؛ مسیرهای قرنطینه‌شده کنار گذاشته می‌شوند و شکست دریافت، دادهٔ قدیمی را به نتیجهٔ جاری تبدیل نمی‌کند. fingerprint شواهد مستقل از انتخاب کاربر برای تاریخچه نگهداری می‌شود؛ fingerprint مصرف برای تشخیص انقضای جزئیات نیز وجود دارد. خواندن کارنامهٔ قدیمی، آن را بازنویسی نمی‌کند. نمایش و چاپ از یک renderer مشترک استفاده می‌کنند.

## هوش مصنوعی

بیان سؤال روشن با متن ثابت انجام می‌شود و تماس پولی جدا برای انتخاب عنوان ندارد. تفسیر پاسخ نوشتنی همان قرارداد محدود، تأیید کاربر، دفتر هزینه و gate عملیاتی قبلی را حفظ می‌کند. توضیح کارنامه فقط شناسهٔ شرط/اقدام و وضعیت مستند را انتخاب می‌کند؛ گزارشِ صرفاً کشف نیز از پیش‌نیازها و اقدامات همان نسخه کارت قابل انتخاب می‌سازد. مقدار بودجه، پاسخ خام و تاریخچه وارد projection توضیح نمی‌شوند.

این تغییر، بودجه یا تاریخ انقضای فعال‌سازی آروان را تمدید نمی‌کند. تنظیم عملیاتی محیط انتشار باید جداگانه جاری و پذیرفته باشد. گزارش پایه هنگام نبود AI قابل استفاده می‌ماند. نخستین کارنامه هنگام ورود به صفحه، اگر گزارش فعلی وجود نداشته باشد، یک‌بار ساخته می‌شود؛ بازکردن نسخهٔ مشخص یا refresh گزارش موجود، تولید دوباره نیست.

## اطلاعات تکمیلی همراه

در کارت مسیر، کاربر موضوع را انتخاب می‌کند و درخواست صریح می‌دهد: شرایط/منابع، هزینه/تمکن، زمان، پرسش، نکات اجرا، زمینه برای ایرانیان، آمار یا تغییرها. API فقط شناسهٔ مسیر و موضوع عمومی را می‌پذیرد؛ پروفایل و نام ابزار دلخواه پذیرفته نمی‌شوند. مقصد MCP عمومی ثابت و credential-free است. شکست انتقال، پوشش داخلیِ partial و شکست پاسخ‌های مرحلهٔ دوم حفظ می‌شوند.

تجربه‌های افراد فقط با کلیک کاربر جست‌وجو می‌شوند. شاخهٔ تحصیلی علاوه بر درخواست صریح، انتخاب API فرصت‌های بررسی‌شدهٔ همراه و رشتهٔ عمومی می‌خواهد. summary فرصت با شناسهٔ پایدار به جزئیات و evidence وصل می‌شود؛ listing به معنی بازبودن فراخوان یا فاند نیست. provider جدید یا جست‌وجوی نام افراد خودکار اضافه نشده است.

## سایت عمومی

بستهٔ وردپرس۱.۰.۴، CTA اصلی، ورودی تحصیل و لینک حساب معمولی را به اپ مشترک می‌برد. لینک‌های بازیابی/ورودی دارای query مربوط به گردش legacy حفظ می‌شوند؛ هویت حساب‌ها بی‌صدا merge نمی‌شود. migration پیشین، backup و حفاظت از ویرایش بعدی محفوظ‌اند. خود این فایل یا ساخت بسته، انتشار روی دامنهٔ زنده نیست.
