# پایگاه دانش خودمیزبان کوچ

این برش به درخواست مالک، جای سرویس پایگاه دانش آروان را برای راهنمای عمومی محصول می‌گیرد. ساخت KB و دیتابیس آروان انجام نشده است. درگاه آروان جدا باقی می‌ماند؛ تولید پاسخ مدل تا تعیین سقف هزینه خاموش است.

اسناد همراه کد در GitHub نسخه می‌گیرند و در build اپ Vercel قرار می‌گیرند. ۱۱ متن سؤال از قرارداد ثابت فرم خوانده می‌شوند؛ چهار مقالهٔ عمومی در `data/knowledge/articles.json` هستند. تغییر محتوا، شناسهٔ SHA-256 مجموعه را تغییر می‌دهد. منشأ، نسخهٔ سؤال/مقاله و تاریخ بازبینی هر متن همراه نتیجه برمی‌گردد. هیچ دادهٔ متقاضی، credential، سیگنال کامیونیتی یا شرط حقوقی در این مجموعه وجود ندارد.

`POST /api/knowledge` ورودی `{ "query": "بودجه و ارز" }` می‌گیرد. پاسخ شامل `scope: product_help`، وضعیت `matched` یا `no_coverage`، حداکثر سه متن با منبع و `context.passages` است. زمینهٔ مدل فقط همین متن‌های قابل استناد است؛ پرسش کاربر یا دستور آن وارد متن منبع نمی‌شود. `generation.enabled` فعلاً false است. `/knowledge` رابط فارسی جست‌وجو و خواندن همهٔ منابع را ارائه می‌کند و از فرم در تب جدا باز می‌شود تا پاسخ ثبت‌نشده از بین نرود.

بازیابی BM25 با نرمال‌سازی حروف فارسی/عربی، حذف اعراب و چند واژهٔ هم‌معنی کنترل‌شده انجام می‌شود. این بازیابی معنایی مبتنی بر embedding نیست؛ برای مجموعهٔ کوچک راهنمای فرم، بدون مدل دانلودی، هزینهٔ API یا دیتابیس جدا کار می‌کند. پوشش موضوعی و کیفیت بازیابی به همین متن‌ها محدود است. برای corpus بزرگ‌تر باید کیفیت جست‌وجو اندازه‌گیری و طراحی تازه انجام شود؛ اطلاعات حقوقی نیازمند سیاست منبع و تازگی مستقل‌اند و خودکار به این corpus اضافه نمی‌شوند.

ورودی حداکثر ۲۰۰ نویسه و بدنه حداکثر ۴۰۹۶ بایت است؛ ورودی اضافی و مبدأ خارجی رد می‌شوند. پاسخ no-store است. درخواست یا پاسخ خصوصی ذخیره نمی‌شود و هیچ شبکهٔ خارجی در مسیر بازیابی وجود ندارد؛ هزینه و محدودیت عادی اجرای پروژهٔ Vercel همچنان برقرار است. سه متن حداکثر ۲۷۰۰ نویسه زمینه می‌دهند. UI متن‌ها را به صورت متن React نمایش می‌دهد و HTML ورودی اجرا نمی‌شود.

مرز آزمون همان API اپ است؛ red اولیه نبود route و red بعدی خطای ورودی نامعتبر بودند. آزمون‌ها بازیابی فارسی، نگارش عربی/اعراب/نیم‌فاصله، منبع نسخه‌دار، پوشش غایب، حجم/مبدأ و خاموش‌بودن تولید پاسخ را می‌سنجند. هیچ smoke تولید متن هزینه‌دار اجرا نشده است. پیاده‌سازی بازیابی به معنی تکمیل اتصال تولید پاسخ، رزرو بودجه و پذیرش تیکت ۰۵ نیست.
