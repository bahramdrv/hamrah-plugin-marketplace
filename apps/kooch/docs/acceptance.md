# پذیرش تیکت ۰۱ — ۱۵ اکتبر ۲۰۲۶

- اپ مستقل: `apps/kooch`؛ Node 22، قفل npm، Next.js 16.4.1 و React 19.3.1. راه‌اندازی و `next build` موفق؛ مسیرهای `/api/config` و `/api/compass` پویا هستند.
- ۱۳ آزمون API/ورود داده: scope ایران، هدف، CEC/PGWP و سابقه، بسته/داخل مقصد، انقضا، صفر نتیجه، شمار متغیر، لینک واقعی، ورودی محدود، بودجهٔ صفر، جدایی مهمان‌ها، حجم و مبدأ، اصلاح پاسخ پیش‌نیاز قبلی و حفظ آخرین snapshot هنگام خطا. شکست اولیهٔ API و adapter قبل از پیاده‌سازی ثبت شد. خطای واقعی مبدأ داخلی Next نیز با آزمون بازتولید اصلاح شد.
- دریافت واقعی از API عمومی با scope ثابت موفق شد؛ فقط دادهٔ عمومی دریافت شد. دریافت دوم با `npm run refresh:data` نیز موفق؛ تاریخ بررسی منابع همان ۱۵ اکتبر و اعتبار همان ۲۹ اکتبر ماند.
- ۳۸۴ آزمون اصلی Node، بررسی انتشار و نحو پاس شدند؛ ۴۷ آزمون Python با `/opt/anaconda3/bin/python3` پاس شدند. Python پیش‌فرض pytest ندارد. دو fixture مهلت ثابت ۱۵/۲۰ اکتبر در آزمون موجود DAAD به مهلت آینده نسبت به زمان اجرا تبدیل شدند؛ کد اجرایی MCP و کار کاربر در آن فایل تغییر داده نشد.
- مرورگر داخلی Codex روی production build: پیمایش هشت گام با پاسخ ساختگی تحصیل/آلمان، ارقام فارسی `۱۵٬۰۰۰`، سؤال شرطی پذیرش، یک نتیجه با `student-de-catalog`، برگشت و حفظ پاسخ، بازیابی پیش‌نویس پس از reload و پاک‌کردن پاسخ‌ها تأیید شدند. پاسخ‌های آزمایشی شخص واقعی نبودند. پس از بازبینی، تغییر پذیرش آلمان از بله به خیر و بازگشت به بله بدون پاک‌کردن پاسخ‌های پایه نیز در مرورگر تأیید شد.
- عرض ۱۴۴۰×۹۰۰ و موبایل ۳۶۰×۸۰۰ بررسی شد. در موبایل `scrollWidth=innerWidth=360`، زبان `fa` و جهت `rtl` تأیید شدند. تصویر viewport استفاده شد؛ ثبت full-page مرورگر داخلی در RTL تصویر را می‌برید و برای ارزیابی استفاده نشد.
- طرح و تصویر آخر با `view_image` مقایسه شدند: زمینهٔ سفید، رنگ و مرز گزینهٔ انتخابی، سلسله‌مراتب قلم فارسی، فرم راست/راهنمای چپ، نوار سه‌مرحله‌ای، دکمه‌ها و تک‌ستون موبایل بررسی شدند. برای عرض میانی، ستون راهنما که باریک می‌شد به زیر فرم منتقل شد. تطبیق ساختار و سبک مرجع تأیید شد؛ متن قانونی و دادهٔ تصویر نمونه با قرارداد واقعی جایگزین شدند، و دو هدف مصوب به گزینه‌ها اضافه شدند. مغایرت بصری مهم شناخته‌شده باقی نماند.

تصویرهای محلی مرورگر در `.scratch/kooch-self-service-app/evidence/` هستند: `form-desktop.png`، `form-mobile.png`، `result-desktop.png` و `result-mobile.png`. جریان اصلی و متن آغاز با موارد مجاز طراحی کنترل شدند؛ تفاوت‌های متن عمدی در بالا ثبت شده‌اند.

انتشار عمومی، حساب، پایگاه داده، AI، اتصال DNS یا پلن پولی ایجاد نشد. این نتیجه فهرست مسیر برای بررسی است؛ ارزیابی تمام شروط یا کارنامهٔ نهایی نیست.

بازبینی مستقل Standards: صفر نقض مستند، یک پیشنهاد غیرمسدودکننده برای جمع‌کردن حلقهٔ خواندن محدود stream در API و adapter. بازبینی Spec: یک P2 در ویرایش پاسخ‌های پیش‌نیاز یافت شد؛ مجموعهٔ سؤال‌های قابل ویرایش از سؤال‌های بی‌پاسخ جدا و مسیر اصلاح مستقل افزوده شد. بازبینی مجدد Spec مانع باقی‌مانده‌ای پیدا نکرد.
