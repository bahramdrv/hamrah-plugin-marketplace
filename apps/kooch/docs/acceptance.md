مالک Supabase Free را برای Auth و PostgreSQL انتخاب کرد؛ SMTP جدا تعیین می‌شود. پیاده‌سازی محلی با PostgreSQL واقعی، Supabase Auth رسمی و تحویل SMTP به Mailpit آزموده شد. پروژهٔ Supabase میزبان، SMTP عمومی و زمان‌بندی پاک‌سازی میزبان هنوز متصل نیستند؛ تیکت در حال انجام است.

TypeScript و build تولید موفق بودند؛ ۳۸۴ آزمون اصلی Node، verify:release، check:static و ۴۷ آزمون Python نیز پاس شدند. جست‌وجوی مقدار واقعی رازهای سرور در فایل‌های JavaScript مرورگر صفر تطبیق داشت. فایل‌های محیطی خارج Git هستند.

مرورگر داخلی روی build تولید و حساب کاملاً ساختگی: نتیجه پیش از ورود، رضایت مستقل و ذخیرهٔ نسخهٔ ۱، ادامهٔ همان پرونده و اصلاح به نسخهٔ ۲ تأیید شدند. خروج از تب دوم، پاسخ‌های خصوصی تب اول را پاک کرد. صفحهٔ حساب در ۱۴۴۰×۹۰۰ و ۳۶۰×۸۰۰ بررسی شد؛ عرض محتوا در موبایل ۳۶۰ و جهت rtl بود. تصاویر account-desktop.png و account-mobile.png در پوشهٔ شواهد محلی با view_image بررسی شدند؛ فرم و راهنما در موبایل یک‌ستون و بدون سرریز هستند.

Site URL روی https://my.kooch.app/account ثبت شد؛ Confirm email فعال است و Minimum password length با پیام Successfully updated settings به ۱۲ تغییر کرد. Data API خاموش است. Resend و Vercel هنوز نشست واردشده ندارند. دامنهٔ my هنگام مراجعه ERR_NAME_NOT_RESOLVED داد؛ NS دامنه kooch.app روی limoodns.com است. قالب ایمیل میزبان تا اتصال SMTP سفارشی قابل ویرایش نیست. هیچ ایمیل عمومی یا انتشار نهایی در این مرحله آزموده/ادعا نشده است.

پشتیبانی کلید جدید sb_secret با دو آزمون مرز REST (شکست اولیه و سپس عبور) افزوده شد. ۱۹ آزمون بدون شبکهٔ اپ، TypeScript و build موفق شدند؛ ۷ آزمون یکپارچهٔ نیازمند Docker در این اجرا skip شدند زیرا daemon خاموش است و راه‌اندازی UI مجوز ندارد. آزمون‌های HTTP مخزن ابتدا با listen EPERM شکست خوردند و با دسترسی localhost هر ۳۸۴ آزمون پاس شدند. verify:release، check:static و ۴۷ آزمون Python نیز پاس شدند.

## تیکت ۰۳ — فرم ثابت، ۱۷ اکتبر ۲۰۲۶

مرز آزمون تأییدشده: API گردش‌کار اپ با Auth/PostgreSQL واقعیِ محلی؛ نه توابع داخلی یا خروجی مدل. پنج سناریوی API، بازاستفادهٔ قطب‌نما، قرارداد سؤال، ذخیره و تکرار هم‌زمان، revision/نسخهٔ دیررس، خروج و ورود، تعارض سن و تأیید، ویرایش وابستگی، نامعلوم/امتناع، ارز بدون تبدیل، جداسازی دو حساب و export را پوشش می‌دهند. شکست اولیهٔ GET فرم 404، سپس POST نسخه‌دار 404، سپس تعارض سنِ نادیده‌گرفته‌شده ثبت و هر برش پس از اصلاح پاس شد.

مرورگر واقعی با پروندهٔ کاملاً مصنوعی روی 127.0.0.1:3103: ادامه از حساب، عدد فارسی ۳۸ و تعارض با بازهٔ زیر ۳۰، تأیید سن، ثبت مقطع با دوبارکلیک (فقط یک revision)، نمی‌دانم، خلاصه و اصلاح مقطع به دکتری و بازشدن پذیرش برای بازبینی مشاهده شدند. پایان نشست، دسترسی خصوصی را قطع کرد؛ ورود دوباره همان نسخه و پاسخ‌ها را بازیابی کرد. با توقف عمدی سرور توسعه، پیام قطع ارتباط و انتخاب ثبت‌نشده در همان صفحه حفظ شدند؛ راه‌اندازی دوبارهٔ Next dev صفحه را reload کرد و انتخاب ثبت‌نشده پاک شد، مطابق محدودیت حافظه. پاسخ‌های قبلاً ثبت‌شده باقی ماندند و ثبت بعدی موفق شد. پس از build، همان قطع/وصل با سرور production محلی هم آزموده شد: ورودی ۲۷ در صفحه حفظ شد، تلاش مجدد پس از بازگشت سرور موفق بود و revision فقط از ۱ به ۲ رفت.

عرض‌های ۱۲۸۰ و ۳۹۰ با `scrollWidth` برابر عرض viewport و جهت RTL بررسی شدند. تصاویر مصنوعی: `.scratch/kooch-self-service-app/evidence/deep-form-desktop.jpg`، `deep-form-mobile.jpg`، `deep-form-summary-desktop.jpg` و `deep-form-summary-mobile.jpg`. کنترل‌های بومی، وضعیت ذخیره، focus و مرور پاسخ قابل استفاده بودند؛ detector رابط یافته‌ای گزارش نکرد. مهاجرت فقط روی دیتابیس آزمایشی اعمال شد. داده، تنظیم یا انتشار production تغییر نکرد.

بازبینی Spec یک تعارض بین سابقهٔ کار قطب‌نما و مقدار دقیق پیدا کرد؛ آزمون ابتدا شکست خورد و پس از بازاستفادهٔ صفر معلوم و تأیید تعارض پاس شد. تصاویر full-page مرورگر در RTL offset نادرست داشتند؛ با تصاویر viewport جایگزین شدند و scrollX=0، عرض واقعی و نبود بریدگی افقی جدا بررسی شدند. بازبینی مجدد Spec رفع تعارض را تأیید کرد و یافتهٔ باقی‌مانده‌ای نداشت. بازبینی مجدد Standards تصاویر و تغییر نهایی را بررسی کرد و ایراد مادی باقی‌مانده‌ای نیافت.

بررسی نهایی: هر ۳۹ آزمون اپ با سرویس‌های واقعی محلی، بدون skip؛ TypeScript، build تولید، verify:release (۱۹ schema و ۵۷ dataset منتشرشده، یک مورد withdrawn)، check:static و هر ۴۷ آزمون Python موفق شدند. Python پیش‌فرض pytest ندارد؛ آزمون‌ها با `/opt/anaconda3/bin/python` اجرا شدند. ۳۸۴ آزمون اصلی Node نیز پاس شدند. کارنامه و ارزیابی شروط حقوقی به تیکت ۰۴ تعلق دارند؛ این برش وضعیت `not_evaluated` و اطلاعات ناقص را صریح نگه می‌دارد.

## پایگاه دانش خودمیزبان — ۱۷ اکتبر ۲۰۲۶

به درخواست مالک، پایگاه دانش آروان ساخته نشد و فهرست آن در پنل خالی تأیید شد. بخش بازیابی در اپ پیاده شد: ۱۱ توضیح سؤال از قرارداد موجود و چهار مقالهٔ راهنمای عمومی، BM25 با نرمال‌سازی فارسی، منبع و نسخهٔ SHA-256 و زمینهٔ محدود برای مدل. تولید پاسخ، embedding و پایگاه دادهٔ تازه وجود ندارند؛ بودجهٔ مدل صفر است.

سه آزمون API عمومی، بازیابی و منبع، نگارش فارسی/عربی/اعراب/نیم‌فاصله، پوشش غایب، اندازه و مبدأ را می‌سنجند. نبود route نخست red بود و پس از پیاده‌سازی green شد؛ ورودی نامعتبر هم ابتدا خطای واقعی داد و با محدودسازی stream و schema رفع شد. هر ۴۲ آزمون اپ با سرویس‌های واقعی محلی و بدون skip، TypeScript و build، ۳۸۴ آزمون ریشه، verify:release، check:static و ۴۷ آزمون Python پاس شدند.

مرورگر روی build تولید محلی: پرسش بودجه متن صحیح با پیوند منبع داد؛ منبع باز و متن اصلی دیده شد. پرسش ورزشی نتیجهٔ ساختگی نداد. با توقف سرور، پیام قطع و همان پرسش حفظ شد؛ پس از راه‌اندازی دوباره، تلاش مجدد راهنمای ذخیره/ادامه را برگرداند. عرض‌های ۱۲۸۰ و ۳۹۰، RTL و scrollWidth برابر viewport تأیید شدند. تصاویر `knowledge-desktop.jpg` و `knowledge-mobile.jpg` با view_image و بازبین مستقل بررسی شدند. Spec صفر مغایرت و Standards صفر ایراد کد یا مشکل بصری باقی‌مانده گزارش کردند. پذیرش انتشار هنوز جداگانه در انتظار است.

## نسخهٔ مستقل عرضهٔ دانش

main شامل فرم عمیق محلیِ منتشرنشده است. برای عرضهٔ راهنما بدون نیاز به مهاجرت دیتابیس، شاخهٔ `codex/kooch-knowledge` از `825132a` ساخته و کامیت `9d8730c` به GitHub ارسال شد. diff کد حساب این شاخه با تولید قبلی `358ee85` خالی است. مجموعهٔ عرضه فقط هشت سؤال قطب‌نمای موجود و چهار مقالهٔ راهنمای همان امکانات را دارد. بازبین‌ها ارجاع اولیه به قابلیت‌های فرم آینده را یافتند؛ یک آزمون API ابتدا شکست خورد و پس از حذف متن‌ها و وابستگی فرم آینده، پاس شد. هر دو بازبینی رفع را تأیید کردند. چهار آزمون دانش، مجموع ۳۸ آزمون اپ و ۳۶۴ آزمون ریشهٔ همین شاخه، ۴۷ آزمون Python، typecheck و build پاس شدند. main با پیوند عمومی راهنما نیز ۴۲ آزمون اپ و ۳۸۴ آزمون ریشه را پاس کرد.

پروژهٔ موجود Vercel `kooch` در `bahramd-s-projects2` به مخزن موجود متصل شد؛ Root Directory برابر `apps/kooch` و شاخهٔ Production برابر `codex/kooch-knowledge` ثبت شدند. با تأیید صریح مالک، Auto-Assign Custom Production Domains خاموش و پس از reload نیز خاموش تأیید شد. هیچ پلن، secret یا تنظیم دیتابیس میزبان تغییر نکرد. build انتشار `6btoi4AChXxxpb8WJYJSyd5sZmVN` از همان `9d8730c` با وضعیت Ready و Assigning Custom Domains Skipped ساخته شد. مرورگر مجاز روی نشانی اختصاصی، جست‌وجوی «اصلاح پاسخ» را با متن درست قطب‌نما و نسخهٔ `592a8f84` برگرداند. نشانی stage دارای حفاظت ورود است؛ درخواست خام بدون نشست 401 گرفت و آن کنترل دور زده نشد. ارتقای دامنه، پذیرش جداگانهٔ نهایی دارد.
