# قطب‌نمای خودخدمت کوچ — برش ۰۱

اپ مستقل Next.js/TypeScript برای مهمانِ دارندهٔ گذرنامهٔ ایرانی ساکن ایران. هشت پاسخ پایه، پیش‌نیازهای مرتبط، حداکثر پنج مسیر برای بررسی، منبع و تاریخ پوشش. حساب، کارنامهٔ کامل، اتصال AI و انتشار عمومی در تیکت‌های بعدی‌اند.

## اجرا

Node.js 22:

```sh
cd apps/kooch
npm ci
npm run dev
```

نشانی: http://127.0.0.1:3100. برای نسخهٔ ساخته‌شده `npm run build` و سپس `npm start`. همهٔ دستورهای اجرا فقط روی loopback گوش می‌دهند. خرید، کلید AI یا سرویس بیرونی لازم نیست. پروژه به پیکربندی انتشار MCP دست نمی‌زند.

```sh
npm run typecheck
npm test
npm run build
```

## داده و حدود نتیجه

- `data/iran-start-snapshot.json` برداشت عمومی ۱۵ اکتبر ۲۰۲۶ از نشانی ثابت API کوچ با `scope=iran-start` است. ۲۹ مسیر روش اقدام مستند، ۷۶ بررسی روش اقدام و ۱۳۳۸ مورد بررسی‌نشده از کاتالوگ ۱۴۱۴تایی دارد؛ شمارها در اجرا از داده خوانده می‌شوند.
- جزئیات شواهد روش اقدام، شناسه‌ها و منابع از بررسی موجود `outputs/kooch-visa-pages/wordpress/kooch-visa-data/iran-application-evidence.json` تطبیق داده شدند. هیچ تاریخ بررسی تازه‌ای به‌واسطهٔ دریافت ساخته نشد. دادهٔ کاتالوگ Visa Atlas با مجوز CC BY 4.0 است؛ انتساب و پیوند مجوز در رابط وجود دارند.
- `src/policy.ts` فقط نگاشت هدف و پیش‌نیاز کشف است؛ موتور احراز تمام شروط نیست. گردشگری و تابعیت از تبار نگاشت پیشنهاد ندارند. CEC و PGWP پیش‌نیاز سابقهٔ مرتبط کانادا دارند. «بله» خوداظهاری است و PASS نمی‌سازد.
- هر مصرف API، تاریخ شواهد، منابع، وضعیت روش اقدام، هدف، مقصد و پیش‌نیاز را دوباره می‌سنجد. نبود داده یا نتیجه با فهرست عمومی بدون scope جایگزین نمی‌شود. خطای قرارداد، 503؛ دادهٔ منقضی، نتیجهٔ بدون مسیر با پیام بازبینی می‌دهد.
- طبق اصلاح مالک در ۱۵ اکتبر، نداشتن پیش‌نیاز آماده‌کردنی مانند پذیرش یا پیشنهاد کار، مسیر مرتبط را پنهان نمی‌کند؛ کارت گام آماده‌سازی آن را نشان می‌دهد. سابقهٔ قبلی لازم برای CEC/PGWP و مدرک مشمول HPI همچنان شرط نمایش مستقیم‌اند. پاسخ منفی به شرطی مثل رابطهٔ خانوادگی نیز مسیر را حذف می‌کند. ترتیب بر اساس ترجیح مقصد، پیش‌نیازهای خوداظهاریِ موجود و شناسهٔ پایدار است؛ نمره یا احتمال صلاحیت نیست.
- نسخهٔ ۲ snapshot، خلاصه و `card_facts` راهنمای موجود `iran-route-guides.json` را با منابع اولیه و تاریخ واقعی همان منبع حفظ می‌کند. مبالغ و شروط فقط با منبع تازه نمایش می‌یابند؛ دریافت دوبارهٔ کاتالوگ این حقایق را بازنویسی یا تاریخشان را تمدید نمی‌کند. تاریخ و پوشش در بخش بازشدنی کارت قرار دارند.
- لینک فقط از `page_url` عمومی معتبر خوانده می‌شود؛ برای نمونه صفحهٔ تحصیل آلمان پسوند `-catalog` دارد. لینک حدس زده نمی‌شود. صفحهٔ منتشرنشده بدون لینک می‌ماند.

## دریافت و بازبینی داده

دریافت روزانه و ادامهٔ دستی از worker دارای checkpoint در PostgreSQL استفاده می‌کنند؛ تغییر شرط/منبع به صف بازبینی می‌رود و تاریخ تأیید رسمی تمدید نمی‌شود. قرارداد چندصفحه‌ای، نصب exporter وردپرس، کلیدهای مستقل مدیر/worker و ترتیب migration/عرضه در [راهنمای sync](docs/evidence-sync.md) هستند. `npm run refresh:data` اکنون همان مسیر امن `npm run evidence:sync` را اجرا می‌کند؛ فایل snapshot بسته‌بندی‌شدهٔ بازبینی‌شده را روی دیسک بازنویسی نمی‌کند.

## حریم خصوصی

جریان کد عضویت تلگرام، معافیت کاربران دارای کارنامه و ترتیب migration/فعال‌سازی در [راهنمای عضویت](docs/membership.md) آمده است. این قابلیت تا تنظیم ربات و انتشار، به‌صورت پیش‌فرض غیرفعال است.

`POST /api/compass` فقط پاسخ‌های ساختارمند مجاز را می‌گیرد؛ نام، ایمیل، تماس و متن آزاد پذیرفته نمی‌شوند. پاسخ‌ها پایدار یا log نمی‌شوند؛ پاسخ‌های API دارای `Cache-Control: no-store` هستند و به ارائه‌دهندهٔ بیرونی نمی‌روند. تنها فایل‌های نوشته‌شوندهٔ دستور دریافت، داده و وضعیت عمومی‌اند. پیش‌نویس اختیاری در `sessionStorage` همان نشست مرورگر است و دکمهٔ پاک‌کردن آن را حذف می‌کند. دادهٔ نامعتبر مرورگر اعتماد نمی‌شود. نتیجهٔ درخواست قدیمی پس از اصلاح پاسخ فعال نمی‌شود.

سؤال‌های پایه از بانک ۴۵تایی وردپرس و سرعنوان‌های ممیزی شیت بررسی و انتخاب شدند. سن، تحصیلات، کار، زبان، بودجه و زمان برای خلأهای اطلاعاتی و قدم بعدی مصرف می‌شوند؛ وزن‌های تاریخی شیت یا تبدیل ارز بدون منبع به رتبه‌بندی وارد نشده‌اند.
