# قطب‌نمای خودخدمت کوچ — برش ۰۱

اپ مستقل Next.js/TypeScript برای مهمانِ دارندهٔ گذرنامهٔ ایرانی ساکن ایران. هشت پاسخ پایه، پیش‌نیازهای مرتبط، حداکثر پنج مسیر برای بررسی، منبع و تاریخ پوشش. حساب، کارنامهٔ کامل، اتصال AI و انتشار عمومی در تیکت‌های بعدی‌اند.

## اجرا

Node.js 22:

```sh
cd apps/kooch
npm ci
npm run dev
```

نشانی: http://127.0.0.1:3100. برای نسخهٔ ساخته‌شده `npm run build` و سپس `npm start`. همهٔ دستورهای اجرا فقط روی loopback گوش می‌دهند. خرید، کلید AI یا سرویس بیرونی لازم نیست. پروژه به پیکربندی انتشار MCP دست نمی‌زند.

```sh
npm run typecheck
npm test
npm run build
```

## داده و حدود نتیجه

- `data/iran-start-snapshot.json` برداشت عمومی ۱۵ اکتبر ۲۰۲۶ از نشانی ثابت API کوچ با `scope=iran-start` است. ۲۹ مسیر کانال مستند، ۷۶ بررسی کانال و ۱۳۳۸ مورد بررسی‌نشده از کاتالوگ ۱۴۱۴تایی دارد؛ شمارها در اجرا از داده خوانده می‌شوند.
- جزئیات شواهد کانال، شناسه‌ها و منابع از بررسی موجود `outputs/kooch-visa-pages/wordpress/kooch-visa-data/iran-application-evidence.json` تطبیق داده شدند. هیچ تاریخ بررسی تازه‌ای به‌واسطهٔ دریافت ساخته نشد. دادهٔ کاتالوگ Visa Atlas با مجوز CC BY 4.0 است؛ انتساب و پیوند مجوز در رابط وجود دارند.
- `src/policy.ts` فقط نگاشت هدف و پیش‌نیاز کشف است؛ موتور احراز تمام شروط نیست. گردشگری و تابعیت از تبار نگاشت پیشنهاد ندارند. CEC و PGWP پیش‌نیاز سابقهٔ مرتبط کانادا دارند. «بله» خوداظهاری است و PASS نمی‌سازد.
- هر مصرف API، تاریخ شواهد، منابع، وضعیت کانال، هدف، مقصد و پیش‌نیاز را دوباره می‌سنجد. نبود داده یا نتیجه با فهرست عمومی بدون scope جایگزین نمی‌شود. خطای قرارداد، 503؛ دادهٔ منقضی، نتیجهٔ بدون مسیر با پیام بازبینی می‌دهد.
- مسیرهای فاقد پیش‌نیاز معلوم در شمار «نیازمند اطلاعات» می‌مانند. برای پرکردن تعداد، مسیر ساخته نمی‌شود. ترتیب صرفاً ترجیح مقصد و ترتیب پایدار شناسه است؛ نمره یا رتبهٔ صلاحیت نیست.
- لینک فقط از `page_url` عمومی معتبر خوانده می‌شود؛ برای نمونه صفحهٔ تحصیل آلمان پسوند `-catalog` دارد. لینک حدس زده نمی‌شود. صفحهٔ منتشرنشده بدون لینک می‌ماند.

## دریافت مجدد

```sh
npm run refresh:data
```

این دستور فقط GET عمومی با نشانی و scope ثابت، کران ۱۵ ثانیه و ۲ مگابایت دارد؛ هیچ پاسخ مهمانی به کوچ یا Atlas نمی‌فرستد. نسخهٔ نخست عمداً تک‌صفحه‌ای و حداکثر صد مسیر است؛ پاسخ ناقص یا بزرگ‌تر پذیرفته نمی‌شود. افزودن مسیر یا تغییر شاهد تصمیم‌ساز به بازبینی جدا نیاز دارد. دریافت، اعتبار رسمی را تمدید نمی‌کند.

شکست دریافت نسخهٔ معتبر قبلی را نگه می‌دارد و وضعیت خطای بدون متن خام را در `data/retrieval-status.json` ثبت می‌کند. تاریخ پایان اعتبار همچنان اعمال می‌شود و خطای دریافت در بخش پوشش دیده می‌شود. پس از دریافت موفق یا ناموفق، سرور محلی را دوباره اجرا کن؛ نسخهٔ production به build تازه نیاز دارد. همگام‌سازی زمان‌بندی‌شده و قرارداد چندصفحه‌ای تیکت بعدی‌اند.

## حریم خصوصی

`POST /api/compass` فقط پاسخ‌های ساختارمند مجاز را می‌گیرد؛ نام، ایمیل، تماس و متن آزاد پذیرفته نمی‌شوند. پاسخ‌ها پایدار یا log نمی‌شوند؛ پاسخ‌های API دارای `Cache-Control: no-store` هستند و به ارائه‌دهندهٔ بیرونی نمی‌روند. تنها فایل‌های نوشته‌شوندهٔ دستور دریافت، داده و وضعیت عمومی‌اند. پیش‌نویس اختیاری در `sessionStorage` همان نشست مرورگر است و دکمهٔ پاک‌کردن آن را حذف می‌کند. دادهٔ نامعتبر مرورگر اعتماد نمی‌شود. نتیجهٔ درخواست قدیمی پس از اصلاح پاسخ فعال نمی‌شود.

سؤال‌های پایه از بانک ۴۵تایی وردپرس و سرعنوان‌های ممیزی شیت بررسی و انتخاب شدند. سن، تحصیلات، کار، زبان، بودجه و زمان برای خلأهای اطلاعاتی و قدم بعدی مصرف می‌شوند؛ وزن‌های تاریخی شیت یا تبدیل ارز بدون منبع به رتبه‌بندی وارد نشده‌اند.
