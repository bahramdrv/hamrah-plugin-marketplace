# کنترل دیداری کوچ — ۲۵ اکتبر ۲۰۲۶

بسته: ۳۰ مسیر/۱۲ مقصد/۱۳۳ سؤال؛ کاتالوگ ۲۳۳ کشور و قلمرو/۱۴۱۴ مسیر. کنترل با Browser درون‌برنامه‌ای، سرور تولید محلی و داده‌های کاملاً ساختگی انجام شد. هیچ دادهٔ متقاضی واقعی، ارسال مدل یا انتشار عمومی در این آزمون نبود.

| بخش | نتیجهٔ مشاهده‌شده |
|---|---|
| شروع دسکتاپ | ناوبری، هدف و گزینه‌ها خوانا؛ تمرکز به سؤال منتقل می‌شود. |
| انتخاب کشور | جست‌وجوی «نیوزیلند» و `Germany` نتیجهٔ درست می‌دهد؛ آلمان انتخاب شد. |
| پاسخ نامعلوم | نامعلوم ثبت می‌شود و بدون تغییر شرط، دوباره پرسیده نمی‌شود. |
| تمرکز مسیر | انتخاب بلوکارت، شرط مدت قرارداد، مدرک، حقوق و مجوز حرفه‌ای را یکی‌یکی باز می‌کند. |
| نتیجه | سناریوی ۱ آماده، ۲ نیازمند اقدام و ۲ نامعلوم درست نمایش داده شد؛ قدم بعدی به نقص قرارداد اشاره دارد. |
| منابع | شرح شرط، اقدام و لینک منبع در جزئیات قابل بازکردن‌اند. |
| هزینه و همراهان | جدا، خوانا و با منبع نمایش داده می‌شوند. |
| موبایل | در عرض ۳۶۰ و ۳۹۰، عرض صفحه و scrollWidth برابر بودند؛ کنترل‌ها و متن خارج از صفحه نرفتند. |
| کاتالوگ | جست‌وجوی هلند ۷ و فیلتر استرالیا ۹ نتیجه داد؛ فهرست کلی از ۱–۱۲ به ۱۳–۲۴ رفت. |
| مقایسه | دو مسیر انتخاب شدند؛ جدول در ظرف خودش به چپ حرکت کرد، بدون بیرون‌زدگی صفحه. |
| بازیابی | پس از بارگذاری مجدد، پیش‌نویس ۸ پاسخ و سؤال بعدی بازیابی شدند. |
| HTML چاپ | از API حساب با پروندهٔ ساختگی صادر شد؛ همهٔ جزئیات باز، منابع و فارسی خوانا بودند. |
| خطاهای مرورگر | در جریان اصلی خطای warning/error ثبت‌شده مشاهده نشد. |

## ایراد کشف و رفع‌شده

پرچم عراق و ساحل عاج در دادهٔ منبع mojibake داشت. نمایش دو مقصد و سازندهٔ کاتالوگ اصلاح شد. آزمون عمومی Compass GET قبل از اصلاح قرمز و پس از اصلاح سبز شد. بعد از build و بارگذاری مجدد، گزینه‌های «🇮🇶 عراق» و «🇨🇮 ساحل عاج» در رابط مشاهده شدند. فقط دو مقدار flag در JSON تغییر کرده‌اند؛ تاریخ دریافت و قواعد ثابت‌اند. دو بازبینی مستقل Standards و Spec پاس شدند.

## حدود پذیرش

این کنترل، سناریوهای بالا و چیدمان واکنش‌گرای آن‌ها را پوشش می‌دهد؛ ۱۴۱۴ مسیر تک‌به‌تک ارزیابی حقوقی یا دیداری نشده‌اند. PDF نهایی، چاپ فیزیکی، مرورگرهای دیگر و همهٔ حالت‌های ورود/بازیابی حساب در این نوبت به‌صورت دیداری تکرار نشدند؛ آزمون‌های حساب و ذخیره/چاپ خودکار پاس شده‌اند. اتصال کلید آروان و rollout دامنهٔ عمومی جزو این تغییر نیستند.
