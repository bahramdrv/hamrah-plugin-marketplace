# منابع و حدود پوشش

بررسی:۲۴اکتبر۲۰۲۶. منبع اصلی کاتالوگ Visa Atlas با CC BY4.0 است. ابزار متصل خروجی هر درخواست را به۱۰۰رکورد محدود می‌کند؛ کاتالوگ با batchهای جدا و completion کشور دقیق خوانده شد و شناسه‌های یکتا با موجودی مستقل منبع تطبیق دارند: **۲۳۳ مقصد/قلمرو و۱۴۱۴رکورد**. درخواست مستقیم شبکه در محیط محلی موفق نشد؛ خروجی نهایی از خود ابزار متصل گرفته شد. ثبت دریافت، تاریخ تأیید شرط یا روش اقدام را تمدید نمی‌کند.

| لایه | مصرف و نتیجهٔ بررسی |
|---|---|
| Visa Atlas destinations/visas | تمام۲۳۳مقصد و۱۴۱۴رکورد در app، نام فارسی، نام اصلی و مرجع |
| روش اقدام ایران در کوچ |۷۶رکورد بررسی اختصاصی؛۲۹رکورد snapshot شروع مستند. اعتبار و دامنهٔ هرکدام مستقل است |
| منابع رسمی جاری | محدودیت آمریکا و استثنا؛ YMS/Working Holiday؛ DAFT؛ چک/آلمان؛ توقف SUV کانادا و دامنهٔ Digital Nomad ترکیه |
| fee/cost/salary/time | دادهٔ موجود به‌ترتیب۳۸/۳۰/۲۱مجموعهٔ مقصد/۹۹رکورد؛ تحقیق اختیاری با دامنهٔ مسیر. فیلترهای MCP و سقف اسکن اصلاح شدند |
| policy updates/claims |۴۹بروزرسانی و۱۶۰claim گزارش‌شده در منبع. capture عمومی claims به۱۰۰رکورد محدود بود؛ تمام۱۶۰claim مصرف‌شده ادعا نمی‌شود |
| processing reliability/skilled accessibility | زمینهٔ برنامه‌ریزی؛ احتمال ویزا یا احراز صلاحیت فردی نیست |

| freshness/answer capsules/citation packs | endpointهای متصل در این بررسی۴۰۴/غیرJSON دادند؛ unavailable ثبت شد، دادهٔ ساختگی جایگزین نشد |
| کامیونیتی |۵۷فایل،۵۶dataset معتبر و۱withdrawn در جست‌وجوی ابزار؛ محدودیت خروجی و داده‌های قدیمی حفظ می‌شود |
| دامنهٔ خاص ایران |در بررسی تک‌تک۲۳۳مقصد با nationality=IRN و originCountry=IRN، فقط آلمان۳سیگنال منطبق داشت؛ این نبود پوشش در سایر کشورهاست، نه نبود اصطکاک |
| زمینهٔ عمومی کشور |در کنار جست‌وجوی دقیق مسیر، به درخواست کاربر دریافت می‌شود، برچسب جدا دارد و به متقاضی ایرانی تعمیم نمی‌یابد؛ جزئیات dataset و فقط evidence همان signal لینک می‌شوند |
| پرسش/claim/viability/statistics |پرسش از answerCommunityQuestion پاسخ منبع‌دار می‌گیرد؛ IRVI با اعتماد و وضعیت ranking جداست. آمار رسمیِ دامنهٔ ایران در این جست‌وجو پوشش نداشت؛ نرخ صفر یا احتمال شخصی ساخته نمی‌شود |
| academic/people |جست‌وجوی تازهٔ برنامه/افراد برای توسعهٔ کاتالوگ انجام نشد؛ قابلیت‌های اختیاری فقط با درخواست صریح و انتخاب API تحصیلی قبلی اجرا می‌شوند |
| normalize/eligibility/finalize/render |ابزارهای پروندهٔ فردی برای این کارِ توسعهٔ محصول اجرا نشدند؛ پرونده یا امتیاز فردی واقعی در اختیار نبود |

جزئیات منابع اولیه در `docs/research/iran-global-route-coverage-2026-10-24.md` و captureها در `.scratch/kooch-global-coverage/evidence/` هستند. جدول `coverage-by-country.csv` برای همهٔ مقصدها، کاتالوگ، بررسی روش اقدام و پوشش سخت‌گیرانهٔ ایران را کنار هم می‌آورد؛ شمار داده‌ها امتیاز یا احتمال ویزا نیست.
