# 03 — Official Source Authority

**What to build:** A facilitator sees official requirement results only when the linked source has a real URL and versioned Source Authority for that exact claim; unsupported requirements remain unverified.

Blocked by: None — can start immediately

Status: done

**Phase:** 1

- [ ] A title alone, missing URL, or non-authoritative source cannot establish official PASS or FAIL in scorecard validation.
- [ ] Automatic source classification is versioned and scoped by claim type; an unknown source yields a Provisional Assessment, not a decisive result.
- [ ] A source-backed requirement retains URL, authority, retrieval and effective dates in its output.
- [ ] End-to-end scorecard tests cover primary authority, unknown authority, and mismatched source scope.
