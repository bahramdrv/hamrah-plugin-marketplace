# NTNU Jobbnorge discovery review — 2026-09-29

- [NTNU's PhD admission and financing page](https://www.ntnu.edu/phd/admission-and-financing) says most PhD candidates are employed research fellows, with positions advertised through NTNU and Jobbnorge. Employment and PhD-programme admission are separate decisions.
- [Grade's Jobbnorge public API guide](https://grade.zammad.com/help/no-no/365-integrasjoner/986-public-api-hvordan-bruke-widgetgeneratoren-for-stillingsannonser-pa-jobbnorge-no) describes employer-filtered active-job display. Its internal-job option requires a separate key, outside this connector.
- [Jobbnorge's NTNU employer search](https://www.jobbnorge.no/search?employer=688) establishes the employer filter. Official Norwegian and English job URLs include the numeric job ID and may include a title slug after it; the parser accepts only the exact ID on those paths.

An approved network request then returned HTTP 200, 103,751 bytes, and a `jobs` array of 80 records. The inspected field names and types match the parser contract: numeric `id` and `employerID`, string `employer`, `title`, `deadline`, `link`, `publicationDate`, and a `locations` array with `isPrimary` and `isDomestic` booleans. No raw API response is retained in the repository.
- A live-response replay through `executeTool("discoverAcademicCallCandidates")` for Norway, `phd`, and `Robotics` returned one `unverified` candidate, ID `308534`, with deadline `2026-10-01`, no source failure, and `apiCoverage: partial`. This is NTNU employer coverage, not all Norwegian PhD vacancies.
- The [exact Jobbnorge page for ID 308534](https://www.jobbnorge.no/en/available-jobs/job/308534/phd-candidate-in-robotics-and-intelligent-mechatronic-systems-for-automated-in-vitro-platforms) loaded in the browser.
