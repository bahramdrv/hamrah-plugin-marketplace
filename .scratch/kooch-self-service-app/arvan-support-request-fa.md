# متن آمادهٔ تیکت برای پشتیبانی رسمی آروان

عنوان: نبود نقش AI محدود به منبع برای ماشین‌یوزر kooch-ai در AI Gateway

سلام،

برای اتصال سمت سرور اپ کوچ به درگاه موجود `kooch` با Endpoint `https://api.arvancloudai.ir/v1`، به مجوز فراخوانی تنها مدل `Qwen3.5-35B-A3B` نیاز داریم. ماشین‌یوزر موجود `kooch-ai` است؛ منبع `kooch-Qwen3-5-35B-A3B-61689` داخل گروه اختصاصی `kooch-ai-only` قرار دارد.

در بررسی ۱۸ اکتبر ۲۰۲۶، «مشاهده قوانین دسترسی متصل» همین ماشین‌یوزر خالی است. انتخاب‌گر نقش برای خود منبع هیچ موردی ندارد؛ در گروه منابع نیز جست‌وجوی «هوش» و «AI» نتیجه ندارد. لطفاً روش اعمال مجوز استفاده از همین مدل، محدود به همین منبع/گروه و ماشین‌یوزر موجود، و علت نبود نقش AI را مشخص کنید. درخواست این تیکت پاسخ فنی و رفع مشکل نمایش نقش‌هاست؛ اعطای دسترسی کل میزکار، تغییر مجوز یا ساخت کلید جدید درخواست نمی‌شود.

برای پذیرش فنی اتصال نیز لطفاً این موارد را روشن کنید:

۱. هدر دقیق raw HTTP برای `POST /v1/chat/completions` این درگاه چیست؟ نمونهٔ curl مستندات `Authorization: apikey …` دارد؛ در نمونهٔ SDK پیشوند داخل apiKey است.
۲. آیا `max_tokens=128` سقف کل خروجیِ قابل صورتحساب، شامل reasoning، است؟ شکل usage و شناسهٔ مدل/درخواست در پاسخ چیست؟ آیا JSON Schema برای مدل منتخب پشتیبانی می‌شود؟
۳. آیا gateway برای همین درخواست retry یا fallback upstream دارد؟ روش خاموش‌کردن یا محدودکردن آن چیست؟
۴. در بازارچهٔ رسمی، نرخ ورودی و خروجی همین مدل هر کدام ۴٬۲۰۰٬۰۰۰ ریال برای یک میلیون توکن درج شده، اما جدول مدل متصل «ـ» نشان می‌دهد. آیا نرخ بازارچه برای این درگاه اعمال می‌شود؟ لطفاً شمول مالیات/هزینهٔ افزوده، شیوهٔ گردکردن و صورتحساب خطا/timeout و تاریخ تعرفه را تأیید کنید.

هنوز تولید پاسخ واقعی انجام نشده است. سپاس.
