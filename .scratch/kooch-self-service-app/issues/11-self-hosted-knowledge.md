# 11: پایگاه دانش کوچ در GitHub و Vercel

**What to build:** به درخواست مستقیم مالک در ۱۷ اکتبر ۲۰۲۶، پایگاه دانش مستقل آروان ساخته نشود؛ اسناد عمومی نسخه‌دار در مخزن GitHub نگهداری و بازیابی متن در همان اپ Vercel اجرا شود. سقف AI فعلاً صفر است.

**Blocked by:** 03 — فرم ثابت و مرتبط (done).

**Status:** in-progress

- [x] مجموعهٔ کوچک راهنمای عمومی فارسی، منشأ و نسخهٔ محتوا و شناسهٔ هر قطعه در Git؛ هیچ دادهٔ متقاضی، credential یا شرط مهاجرتی اضافه نشود.
- [x] بازیابی محدود و قطعی با نرمال‌سازی فارسی، نتیجهٔ بی‌پوشش روشن و قطعه‌های قابل استناد؛ زمینهٔ محدود آمادهٔ مصرف مدل باشد، ولی هیچ فراخوانی مدل یا امبدینگ هزینه‌دار انجام نشود.
- [x] مرز آزمون همان API عمومی اپ، مطابق توافق قبلی: ورودی معتبر/نامعتبر، فارسی و عربی، جست‌وجوی بی‌پاسخ، منبع، اندازه و مبدأ؛ آزمون شبکهٔ AI لازم نیست.
- [x] صفحهٔ فارسی جست‌وجو و خواندن منابع در اپ، بدون ذخیره یا ارسال بیرونی پرسش و با حالت خطا و موبایل قابل استفاده.
- [ ] آزمون‌ها، build و دو بازبینی مستقل پاس شوند؛ فقط تغییرات این کار کامیت و به GitHub ارسال شوند و نسخهٔ همان commit در پروژهٔ موجود kooch در Vercel بررسی شود.

این برش، بخش بازیابی و آماده‌سازی زمینهٔ RAG است. تولید پاسخ با مدل تا تعیین بودجه خاموش می‌ماند. شرایط حقوقی مسیرها و کارنامه به قواعد و منابع مستقل موجود تعلق دارند. ساخت دیتابیس، امبدینگ، پلن پولی یا پایگاه دانش آروان مجاز نیست.

پذیرش محلی: ۴۲ آزمون اپ بدون skip، ۳۸۴ آزمون ریشه، ۴۷ آزمون Python، TypeScript، build، verify:release و check:static موفق‌اند. Spec و Standards پس از بررسی کد و تصاویر، یافتهٔ بازی ندارند. عرضهٔ راهنما روی کد حسابِ فعلی production آماده می‌شود تا به مهاجرت منتشرنشدهٔ فرم ۰۳ وابسته نباشد؛ main همچنان پیاده‌سازی کامل فرم و پیوند راهنما را دارد. انتشار، پس از آماده‌شدن snapshot مستقل، بررسی می‌شود.
