# 03: فرم عمیق ثابت و مرتبط

**What to build:** کاربر واردشده هر بار یک سؤال مرتبط و قابل فهم می‌بیند، پاسخ می‌دهد، سؤال قبلی را اصلاح می‌کند و هر زمان می‌تواند نتیجهٔ ناقص یا ادامهٔ بعدی را انتخاب کند؛ این مسیر به AI وابسته نیست.

**Blocked by:** 02 — حساب ایمیلی و ادامهٔ پاسخ‌ها.

**Status:** done

- [x] قرارداد نسخه‌دار سؤال و پاسخ با گزینه‌های مجاز، نوع ورودی، واحد، دلیل پرسش و حالت نامعلوم/امتناع در موارد مجاز.
- [x] اطلاعات مشترک یک بار پرسیده شود؛ پاسخ بازه‌ای قطب‌نما برای شرط آستانه‌دار به مقدار دقیق تبدیل شود، بدون تبدیل ارز حدسی.
- [x] سؤال بعدی با اولویت تعارض، شرط مهم و اطلاعات مؤثر انتخاب شود؛ شرایط مسیر از متن مدل ساخته نشوند.
- [x] revision، request و question version مانع ثبت پاسخ دیررس و دوباره‌کاری شوند؛ ویرایش پاسخ قبلی پرسش‌ها و ارزیابی وابسته را بازبینی کند.
- [x] قطع ارتباط، refresh، خروج و ورود دوباره پیشرفت تأییدشده را حفظ کنند؛ رابط در زمان ارسال وضعیت روشن داشته باشد.
- [x] پاسخ‌ها قابل مرور/ویرایش و نتیجهٔ ناقص مجاز باشد؛ درصد پیشرفتِ مبتنی بر تعداد سؤال نامعلوم نمایش داده نشود.
- [x] تست گردش‌کار و مرورگر، تعارض، نمی‌دانم، دوبارکلیک، اصلاح، قطع و ادامه را از مرز عمومی پوشش دهد.

پذیرش ۱۷ اکتبر ۲۰۲۶: ۳۹ آزمون اپ با Auth/PostgreSQL واقعی محلی و بدون skip، TypeScript و build موفق شدند. مرورگر production محلی، قطع/وصل، تکرار امن، بازبینی تعارض و نمای موبایل/دسکتاپ را تأیید کرد. جزئیات و شواهد در `apps/kooch/docs/acceptance.md` ثبت‌اند. بازبینی مستقل Spec و Standards پس از اصلاح، یافتهٔ باز ندارند. مهاجرت ۰۰۲ فقط محلی اجرا شد؛ انتشار و مهاجرت میزبان انجام نشده‌اند. این برش خلاصهٔ پاسخ‌ها را می‌دهد؛ ارزیابی مستند و کارنامهٔ مقدماتی در تیکت ۰۴ است.
