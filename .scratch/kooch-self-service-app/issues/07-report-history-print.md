# 07: حساب من، تاریخچه و چاپ فارسی

**What to build:** کاربر در حساب خود کارنامه‌های مقدماتی را با تاریخ و دلیل تغییر می‌بیند، اطلاعات را اصلاح می‌کند و نسخهٔ فارسی خوانا چاپ می‌کند.

**Blocked by:** 04 — نخستین کارنامهٔ مقدماتی واقعی.

**Status:** done

- [x] فهرست گزارش‌ها و ادامهٔ پرونده در حساب؛ خواندن گزارش و خروجی چاپی فقط با owner و نشست معتبر.
- [x] اصلاح پاسخ یا منبع، گزارش جدید بسازد؛ نسخهٔ پیشین و وابستگی‌های آن تغییر نکنند.
- [x] تغییر پاسخ فرد از تغییر شواهد جدا توضیح داده شود؛ وضعیت قدیمی/نیازمند بازبینی آشکار باشد.
- [x] گزارش ناقص بدون پرکردن مصنوعی شرط‌ها ذخیره شود؛ دادهٔ مالی نامعلوم و سطح پوشش حفظ شوند.
- [x] HTML فارسی A4 با قلم محلی، RTL، منابع قابل خواندن و شکست صفحهٔ مناسب؛ چاپ مرورگر بدون سرویس پولی PDF.
- [x] تست دو حساب برای URL و چاپ، snapshot تغییرناپذیر، تغییر نسخه و مرورگر موبایل/بزرگ‌نمایی/صفحه‌کلید.

**ارتباط با توضیح AI:** این تیکت برای گزارش پایه مستقل از ۱۲ است. وقتی افزودهٔ نسخه‌دار ۱۲ موجود باشد، تاریخچه/چاپ همان نسخهٔ ذخیره‌شده را می‌خواند؛ بازکردن صفحه یا چاپ باعث inference تازه یا تغییر متن قبلی نمی‌شود. اتصال و پذیرش افزوده در رابط موجود در دامنهٔ تیکت ۱۲ است.

**پذیرش ۲۱ اکتبر ۲۰۲۶:** تاریخچهٔ مالک‌دار، لینک نسخهٔ مشخص، علت تغییر مستقل پاسخ/شواهد و HTML چاپ A4 پیاده شد. ۱۰۰ تست اپ، ۳۸۴ تست مخزن، ۴۷ تست Python، build/typecheck، verify:release و check:static گذشتند. مرورگر محلی با دو نسخهٔ مصنوعی، موبایل/بازچینی معادل بزرگ‌نمایی/صفحه‌کلید و PDF A4 بررسی شد. جزئیات و حدود پذیرش در [راهنمای کارنامه](../../../apps/kooch/docs/guidance-report.md) ثبت شده است. عرضهٔ production انجام نشده است.
