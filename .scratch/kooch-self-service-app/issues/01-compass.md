# 01: قطب‌نمای فارسی و فهرست مستند

**What to build:** کاربر بدون حساب چند پاسخ کوتاه می‌دهد و حداکثر ۳ تا ۵ مسیر مهاجرتی مرتبط با دلیل و سطح پوشش می‌بیند. این برش در اپ مستقل محلی، از قرارداد داده تا API و رابط واقعی قابل نمایش است.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] اپ مستقل فارسی و RTL با اجرای محلی و build تکرارپذیر؛ پروژهٔ MCP و اپ کارشناسی موجود تغییر رفتار نکنند.
- [x] بانک سؤال و سرفصل‌های موجود بررسی شود؛ هدف، سن، تحصیلات، کار، زبان، بودجه با ارز، مقصد و زمان با کمترین سؤال لازم گرفته شوند.

- [x] نتیجه پیش از ورود نمایش یابد؛ اطلاعات مهمان در سرور پایدار یا log ذخیره نشود و پیش‌نویس مرورگر پاک‌کردنی باشد.
