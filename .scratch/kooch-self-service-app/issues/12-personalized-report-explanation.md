# 12: توضیح شخصی و اقدام بعدی از کارنامهٔ مستند

**What to build:** کاربر پس از ساخت کارنامهٔ مقدماتی، توضیح فارسی متناسب با وضعیت خود و اقدامات بعدی را از همان نتایج و منابع ببیند؛ در نبود AI معتبر، گزارش قالبی بلافاصله قابل استفاده بماند. مالک این قابلیت و حد دادهٔ ارسالی را در ۱۷ اکتبر ۲۰۲۶ تأیید کرد.

**Blocked by:** 04 — نخستین کارنامهٔ مقدماتی واقعی؛ 05 — اتصال گیت‌وی آروان و کمک هوشمند برای بیان سؤال.

**Status:** in-progress

**External prerequisites:** پذیرش مستقل task توضیح کارنامه برای مدل/endpoint/پرامپت/قرارداد و سیاست داده؛ تعرفهٔ معلوم و سقف مثبت برای تولید واقعی. بودجهٔ فعلی صفر است؛ ساخت و آزمون با transport شبیه‌سازی‌شده انجام می‌شود و smoke هزینه‌دار مجاز نیست.

- [x] ورودی فقط projection ضروری و allowlist از یک نسخهٔ کارنامه: هدف و ترجیح مرتبط، وضعیت شروط، موانع و خلأها، هزینه‌های مستند با واحد، اقدام‌های مجاز و شناسهٔ منابع مصرف‌شده. مقدار شخصی فقط وقتی برای توضیح لازم است؛ نام/تماس/ایمیل/شناسهٔ حساب، مدارک، متن آزاد خام و تاریخچهٔ کامل ارسال نشوند.
- [ ] منشأ خوداظهاری و وضعیت نامعلوم حفظ شوند؛ خلاصهٔ بدون نام همچنان دادهٔ خصوصی محسوب و اطلاع‌رسانی گیرنده/نگهداری اعمال شود. تیکت ۱۱ راهنمای محصول شاهد قانونی یا پیش‌نیاز این قابلیت نیست.
- [x] خروجی محدود به توضیح فارسی، دلایل و اقدامات بعدیِ متصل به result/claim/action IDهای مجاز باشد؛ مدل نتیجهٔ جدید، مسیر، شرط، رقم، تاریخ، رتبه، احتمال ویزا یا URL تازه نسازد. نمایش حقایق و اعداد از گزارش پایه انجام شود و متن خارج از دامنه رد شود.
- [x] validator فقط schema را نسنجد؛ شناسه‌ها، انطباق توضیح با وضعیت شرط، حفظ ناشناخته‌ها و ادعاهای فاقد پشتوانه را کنترل کند. تشخیص‌ندادن ادعای تازه در آزمون‌ها مانع فعال‌سازی همان قالب شود؛ صحت‌سنجی کامل نثر آزاد فرض نشود.
- [ ] گزارش پایه پیش از تولید توضیح ذخیره و نمایش داده شود؛ نمایش گزارش به انتظار AI وابسته نباشد. تولید پس از ساخت نسخهٔ تازه و فقط با سهمیهٔ مجاز آغاز شود؛ خواندن/چاپ/refresh تولید یا هزینهٔ تازه نسازد.
- [ ] تولید با owner، report version، policy/model/prompt/schema versions و request ID یکتا کنترل شود؛ هر کار یکسان فقط یک رزرو هزینه داشته باشد. شکست یا timeout از قرارداد هزینهٔ نامعلوم تیکت ۰۵ پیروی کند و retry خودکار پنهان نداشته باشد.
- [ ] افزودهٔ توضیح تغییرناپذیر، تاریخ‌دار و همراه provenance ذخیره شود؛ بازتولید صریح و مجاز نسخهٔ تازه بسازد. متن آماده‌شده پس از نمایش اولیه با اعلان و اقدام روشن کاربر باز شود، نه با بازنویسی بی‌خبر گزارش جاری.
- [x] پس از حذف پرونده/حساب، تغییر revision مبنا یا بی‌اعتبارشدن گزارش، نتیجهٔ دیررس دور انداخته شود؛ completion مدل دادهٔ حذف‌شده را دوباره نسازد. متن افزوده با همان مالکیت، export و نگهداری ۹۰روزهٔ پرونده حذف شود.
- [ ] بودجهٔ صفر، نبود مدل پذیرفته‌شده، پوشش ناکافی، ۴۲۹، امتناع، خطای schema و timeout گزارش قالبی را حفظ کنند؛ برچسب نسخه/پوشش و توضیح وضعیت قابل فهم باشند. «بدون پوشش» به «نامناسب برای فرد» تبدیل نشود.
- [ ] آزمون از API گردش‌کار برای مالکیت دو حساب، دادهٔ حداقلی، صفر فراخوانی در بودجهٔ صفر، شناسه/عدد/منبع اختراعی، متن دستوری در داده، تکرار درخواست، نتیجهٔ دیررس و ثابت‌ماندن نسخه؛ یک مسیر مرورگر از ساخت گزارش تا مشاهده و چاپ افزوده.
- [ ] پذیرش فارسی با نمونه‌های کامل/ناقص/متعارض، بودجهٔ نامعلوم، چند شرط وابسته و مسیر مشروط ثبت شود؛ پذیرش بیان سؤال یا تفسیر پاسخ به این task تعمیم داده نشود.

این تیکت موتور تصمیم‌ساز یا صدور کارشناسی را تغییر نمی‌دهد؛ ADR-0010، ADR-0011 و قواعد اعتبار منبع باید رعایت شوند. تکمیل آن به معنی فعال‌شدن مدل در production نیست.


## پیاده‌سازی محلی — ۲۲ اکتبر۲۰۲۶

طبق ادامهٔ صریح مالک، پیاده‌سازی با مرز عمومی API حساب و transport شبیه‌سازی‌شده آغاز شد. انتخاب شناسهٔ کارت‌های مستند جای نثر آزاد است؛ گزارش پایه مستقل و ثابت است. migration۰۰۷ فقط local اعمال شد؛ API owner/RLS، job یکتا، خروجی افزوده، رد شناسه/عدد/URL اختراعی، بودجه صفر، task پذیرفته‌نشده، پذیرش دادهٔ مستقل غایب/منقضی،۴۲۹ و دورریختن نتیجهٔ دیررس پس از اصلاح/حذف آزموده شدند. راهنمای دقیق: apps/kooch/docs/report-explanation.md.

بازبینی نخست Standards بدون یافته و Spec با دو یافته بود: پذیرش مستقل پردازش projection و retry UI. هر دو در gate و UI اصلاح شدند؛ شناسهٔ pending از GET بازیابی می‌شود. فعال‌سازی واقعی، اجرای migration میزبان و پذیرش مرورگر/فارسی واقعی هنوز انجام نشده‌اند؛ این تیکت done نیست. کار تازه روی PDF و متن اطلاع‌رسانی مشتری با دستور صریح مالک از دامنهٔ این ادامه خارج است.

بررسی نهایی۱۲۹اپ/۳۸۴مخزن/۴۷Python وtype/build/release/static موفق بود. ابزار مرورگر اعلام کرد Local browser use در Work settings خاموش است؛ پذیرش تعاملی UI مسدود ماند. حساب disposable محلیِ آماده‌شده حذف و سرور موقت بسته شد؛ هیچ fixture یا credential تازه در Production ساخته نشد.
