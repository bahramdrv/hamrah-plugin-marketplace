# 02: حساب ایمیلی و ادامهٔ پاسخ‌ها

**What to build:** کاربر پس از مشاهدهٔ قطب‌نما حساب مستقل می‌سازد، پاسخ‌هایش را آگاهانه ذخیره می‌کند و پس از خروج و ورود دوباره از همان پرونده ادامه می‌دهد.

**Blocked by:** 01 — قطب‌نمای فارسی و فهرست مستند.

**Status:** in-progress

**External prerequisites:** مالک Supabase Free را برای Auth/PostgreSQL انتخاب کرد؛ پروژهٔ رایگان `kooch` با شناسهٔ `ifjtceqlcsmypuuflwlx` در ایرلند ساخته و schema با تأیید مالک اعمال شد؛ اتصال runtime، SMTP سفارشی و DNS/میزبانی عمومی هنوز پذیرفته نشده‌اند. Resend فعلاً فقط بررسی شده است. بدون سرویس عملیاتی، چرخهٔ ورود عمومی انجام‌شده اعلام نشود؛ ساخت و آزمون محلی مستقل ادامه یابد. پرداخت یا ارتقا انجام نشود.

- [x] ثبت‌نام با ایمیل/رمز، تأیید، ورود، خروج و بازیابی رمز با نشست معتبر و پیام فارسی؛ وجود حساب در پیام خطا افشا نشود.
- [x] انتقال پاسخ مهمان فقط پس از ورود و اقدام روشن کاربر؛ اتصال بر اساس ایمیل حدسی یا پارامتر URL انجام نشود.
- [x] یک پروندهٔ فعال برای هر حساب با owner سمت سرور، revision و شناسهٔ درخواست؛ شناسهٔ مالک از ورودی پذیرفته نشود.
- [x] RLS و کنترل سرور برای خواندن/نوشتن، ادامه، export و حذف؛ کلید مدیریتی هرگز در مرورگر قرار نگیرد.
- [x] تست دو حساب شامل شناسهٔ پروندهٔ دیگری، درخواست مستقیم و cache؛ نشست منقضی/لغوشده حق دسترسی نداشته باشد.
- [x] حذف پایهٔ حساب، پرونده و پیش‌نویس و export امن قابل استفاده باشند؛ دادهٔ خصوصی no-store باشد.
- [x] تاریخ پاک‌شدن پس از ۹۰ روز بی‌فعالیتی نمایش یابد؛ صرف مشاهده یا cron فعالیت محسوب نشود.
- [ ] تحویل ایمیل تأیید/بازیابی با SMTP واقعی و دادهٔ آزمایشی ثبت شود؛ SMTP آزمایشی محدود جای اتصال عمومی را نگیرد.

**Local acceptance:** موارد علامت‌خورده در اتصال واقعی محلی PostgreSQL/Supabase Auth و صندوق SMTP آزمایشی پذیرفته شده‌اند؛ پذیرش عمومی پس از اتصال پروژهٔ میزبان و SMTP واقعی باز است. شواهد در `apps/kooch/docs/acceptance.md` و روش اجرا در `apps/kooch/docs/account.md` ثبت شده‌اند.
