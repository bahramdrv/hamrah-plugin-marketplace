# 02: حساب ایمیلی و ادامهٔ پاسخ‌ها

**What to build:** کاربر پس از مشاهدهٔ قطب‌نما حساب مستقل می‌سازد، پاسخ‌هایش را آگاهانه ذخیره می‌کند و پس از خروج و ورود دوباره از همان پرونده ادامه می‌دهد.

**Blocked by:** 01 — قطب‌نمای فارسی و فهرست مستند.

**Status:** done

**External prerequisites:** Supabase Free پروژهٔ `kooch` با شناسهٔ `ifjtceqlcsmypuuflwlx` در ایرلند، runtime محدود PostgreSQL با TLS معتبر، دامنهٔ HTTPS `my.kooch.app` و Resend SMTP متصل‌اند. تحویل تأیید و بازیابی، ثبت رمز تازه توسط مالک و ورود با آن روی دامنهٔ اصلی پذیرفته شدند. job داخلی پاک‌سازی ساعتی فعال است؛ جداسازی دو حساب و چرخهٔ پرونده با سرویس‌های واقعی محلی آزموده شده‌اند. پرداخت یا ارتقا انجام نشود.

**Scope addition (2026-10-17):** مالک ورود با گوگل و پروژهٔ رایگان جداگانهٔ Google Cloud برای کوچ را درخواست کرد. این روش باید همان نشست و کنترل مالکیت حساب را استفاده کند؛ تأیید Google نباید به اتصال پرونده از روی ایمیل حدسی منجر شود.

- [x] ثبت‌نام با ایمیل/رمز، تأیید، ورود، خروج و بازیابی رمز با نشست معتبر و پیام فارسی؛ وجود حساب در پیام خطا افشا نشود.
- [x] انتقال پاسخ مهمان فقط پس از ورود و اقدام روشن کاربر؛ اتصال بر اساس ایمیل حدسی یا پارامتر URL انجام نشود.
- [x] یک پروندهٔ فعال برای هر حساب با owner سمت سرور، revision و شناسهٔ درخواست؛ شناسهٔ مالک از ورودی پذیرفته نشود.
- [x] RLS و کنترل سرور برای خواندن/نوشتن، ادامه، export و حذف؛ کلید مدیریتی هرگز در مرورگر قرار نگیرد.
- [x] تست دو حساب شامل شناسهٔ پروندهٔ دیگری، درخواست مستقیم و cache؛ نشست منقضی/لغوشده حق دسترسی نداشته باشد.
- [x] حذف پایهٔ حساب، پرونده و پیش‌نویس و export امن قابل استفاده باشند؛ دادهٔ خصوصی no-store باشد.
- [x] تاریخ پاک‌شدن پس از ۹۰ روز بی‌فعالیتی نمایش یابد؛ صرف مشاهده یا cron فعالیت محسوب نشود.
- [x] تحویل ایمیل تأیید/بازیابی با SMTP واقعی و دادهٔ آزمایشی ثبت شود؛ SMTP آزمایشی محدود جای اتصال عمومی را نگیرد.
- [x] ورود گوگل با PKCE و بازگشت محدود به دامنهٔ اپ، کلید OAuth فقط در Supabase، و آزمون واقعی سرویس گوگل روی میزبانی.

**Local acceptance:** موارد علامت‌خورده در اتصال واقعی محلی PostgreSQL/Supabase Auth و صندوق SMTP آزمایشی پذیرفته شده‌اند؛ پذیرش ایمیل و ورود عمومی روی دامنهٔ اصلی و نصب job در ادامه تکمیل شدند. شواهد در `apps/kooch/docs/acceptance.md` و روش اجرا در `apps/kooch/docs/account.md` ثبت شده‌اند.
