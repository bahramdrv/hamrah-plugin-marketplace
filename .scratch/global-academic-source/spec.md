# Broader free academic discovery

User request 2026-10-01: connect a genuinely free API that can discover academic openings across many universities and countries; request registration/key only when necessary. User subsequently authorized setting the existing JSearch key through the browser.

Primary-source comparison is in docs/global-academic-api-research-2026-10-01.md. Prepare a JSearch connector using the existing public executeTool seam. Enable only with actual free plan verification and key in server environment; provider Basic/Free hard cap 200 credits/month. One page per requested country, bounded scope, no retries/automatic paid upgrade, no caller profile or persistence. Return unverified leads and exact requested/checked countries. A global request may only check a disclosed small set of countries, never claim worldwide coverage. Source-reported application links remain unverified; host must inspect exact current official institutional posting on each request. Master's admissions remain outside job-search coverage.

AcademicJobsOnline officially linked RSS is a useful additional free academic source (observed 101 employers/20 countries); it is not a global REST API or proof that all listed jobs accept applications. It is researched separately, not a reason to misstate JSearch's university coverage.
