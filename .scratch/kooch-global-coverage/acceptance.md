# پذیرش گسترش پوشش جهانی کوچ

Baseline: acbb3bb. مرجع رفتار: spec.md. دادهٔ فعلی و نسخهٔ قبل از تغییر app در /private/tmp/kooch-global-baseline-20261024 جدا نگهداری شدند. allowlist تغییرهای این کار evidence/changed-files.json است؛ کارهای academic discovery، backup، بودجهٔ AI و production window وارد بسته نشده‌اند.

## دامنهٔ اجراشده

۲۳۳ کشور/قلمرو و۱۴۱۴رکورد یکتای Visa Atlas به اپ اضافه شدند؛ نام فارسی و عنوان اصلی، جست‌وجو و فیلتر گروه/مقصد، صفحه‌بندی و انتخاب یک مسیر برای ادامهٔ مصاحبه وجود دارد. خلاصهٔ حداکثر۵مسیر برای مرور اولیه است و تمام رکوردها در مرورگر کاتالوگ قابل دسترسی‌اند. گروه‌های بازدید/تبار/بشردوستانه و مرجع عمومی به‌عنوان مسیر کاری یا تحصیلی خودکار پیشنهاد نمی‌شوند.

روش اقدام ایران، رتبه‌بندی و شرایط فردی از موجودیت رکورد جدا هستند.۷۶بررسی روش اقدام از قبل حفظ شده‌اند و۲۹مسیر snapshot اصلی تاریخ و منبع خود را دارند. آمریکا و استثنا، برنامه‌های تابعیت‌محور جوانان، DAFT، توقف SUV کانادا و روش اقدام محدود کشورها با منبع و دامنه مشخص‌اند. عدم پوشش، بسته‌بودن مسیر نیست. generic prerequisites سؤال آماده‌سازی هستند و PASS/FAIL فردی یا احتمال ویزا تولید نمی‌کنند.

کامیونیتی با کشور alpha-3 و alias مسیر دقیق جست‌وجو می‌شود؛ زمینهٔ عمومی کشور جدا و بدون تعمیم به متقاضی نشان داده می‌شود. فقط signal انتخاب‌شده از dataset معتبر گسترش می‌یابد و evidence همان signal استناد می‌شود؛ محدودیت خروجی و تاریخ گذشته partial می‌مانند. هیچ دادهٔ تازهٔ افراد/دانشگاه، dataset منتشرشده یا phrase allowlist تغییر نکرده است.

## Standards — بررسی عامل اصلی

- نقض مهمی که در بررسی پیدا شد و رفع شد: مسیر قرنطینه‌شده می‌توانست از کاتالوگ دوباره وارد شود؛ blockedRouteIds اکنون در shortlist، مرور و ساخت گزارش رعایت می‌شود.
- منبع Visa Atlas trusted است؛ دریافت تازه، تاریخ تأیید اولیه را تمدید نمی‌کند. دادهٔ قدیمی و روش اقدام منقضی به verified تبدیل نمی‌شوند.
- فیلتر MCP اکنون destinationIso/visaSlug، aliasهای کشور، thresholds تو‌در‌تو و rows را می‌خواند؛ اسکن Route Fact Pack۲۰۰۰رکورد محدود و محدودیت خروجی۲۵رکورد افشا می‌شود.
- generic fact ID فقط برای کشور و نوع سؤال شناخته‌شده پذیرفته می‌شود. arbitrary tool/profile در API تحقیق پذیرفته نمی‌شود؛ هیچ secret داخل بسته نیست.

## Spec — بررسی عامل اصلی

- کمبود نمایش مسیرهای پس از تحصیل رفع شد: انتخاب صریح مسیر، سؤال سابقهٔ لازم را پیش از ورود آن به shortlist نشان می‌دهد. Orientation Year هلند به سابقهٔ تحصیل صرفاً داخلی محدود نشده است؛ منبع، فارغ‌التحصیلی خارجی مشخص را هم می‌شناسد.
- انقضای گزارش قدیمی به بازنویسی آن منجر نمی‌شود. گزارش پژوهشی جدید می‌تواند مسیرهای research_only را نشان دهد و needs_review دارد.
- API حساب با استرالیا و ذخیره/خواندن/چاپ نسخه۱ آزمایش شد؛ ماژول حقوقی نامرتبط صادر نمی‌شود و refresh نسخهٔ تازه نمی‌سازد.

دو زیرعامل برای بازبینی مستقل Standards و Spec فراخوانی شدند؛ هر دو با خطای سقف مصرف حساب متوقف شدند. پژوهشگر منابع رسمی پیش‌تر گزارش خود را تحویل داده است. تأیید بازبینی مستقل کد ادعا نمی‌شود.

## بررسی‌های خودکار

خود بستهٔ جدا در evidence/delivery-tests.tap: **۱۶۴از۱۶۴تست موفق** و evidence/delivery-build.txt: **ساخت تولید موفق**؛ typecheck و۳۷تست هدفمند موفق‌اند. تست‌های مخزن۳۸۸موفق، verify:release موفق (۱۹schema،۵۷dataset و۱withdrawn)، check:static موفق، چهار مجموعهٔ Python مقرر۴۷موفق. پس از این بررسی‌های root، تغییر جدیدی در فایل‌های ابزار MCP داده نشد.

## محدودیت مرورگر و انتشار

CUA سه بار پیام Local browser use is disabled in Work settings داد، از جمله پس از پاسخ مالک مبنی بر فعال‌سازی. کنترل browser با ابزار دیگری جایگزین نشد و screenshot تازه یا تأیید بصری موبایل/دسکتاپ ادعا نمی‌شود. پیش‌نمایش محلی برای بررسی مالک در http://127.0.0.1:3100/ آماده است؛ فقط دادهٔ مصنوعی وارد شود. این مانع به معنی شکست build یا تست API نیست.

هیچ push، deployment روی my.kooch.app یا kooch.app، انتشار MCP، تغییر پنل یا تماس پولی آروان انجام نشده است. برای بهره‌برداری زنده از اصلاح ابزارها، overlay MCP و app باید با هم و بعد از اجازهٔ انتشار نصب شوند؛ مرز ماژول‌های حقوقی موجود UK/CA study تغییر نکرده است.
