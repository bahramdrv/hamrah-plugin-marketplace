# 02: Verified opening shortlist and academic fit

**What to build:** A request for doctoral physics positions in Germany returns up to five verified open funded openings and a source-linked comparison with the applicant's supplied academic facts. When fewer qualify, Hamrah shows the actual number and the search coverage without widening the requested scope.

**Blocked by:** 01 — One Verified Open Academic Opportunity

**Status:** done

- [x] An explicit request returns three to five qualifying openings when available, or fewer including zero with scope and exclusion reasons. It never silently widens country, field, degree, or position type.
- [x] Each position keeps opening status, deadline or rolling call, salary or stipend terms, academic conditions, nationality evidence, and check date visibly separate and source-linked.
- [x] Supplied academic facts are compared with published conditions in private, source-linked fit notes. Missing applicant proof is a gap; a minimal profile still permits discovery. No admission or visa probability is reported.
- [x] Applicant profile details, private fit reasons, and gaps are absent from the public renderer input and remain outside published datasets.
- [x] An unstated Iranian-nationality condition is labelled unknown; silence is not reported as permission or restriction.
- [x] Tests at the visible tool seam cover multiple results, fewer or zero qualifying results, unknown applicant facts, and complete status blocks in the final answer.

See the feature specification in the parent directory for scope, terminology, and privacy boundaries.
