# Architecture Notes

## Runtime data planes

**A. Static Knowledge**
- instructions support
- scoring method
- consent/interview playbook
- schemas
- processed community JSON

**B. Live Actions**
- Visa Atlas public APIs

**C. Web**
- official verification
- university positions
- monthly living cost
- operational facts outside Visa Atlas coverage

**D. Approved calculators**
- deterministic formulas only when inputs complete + consent

## Avoid
- copying live Visa Atlas datasets into Knowledge
- uploading raw Telegram exports to Main GPT
- mixing community claims with legal rules
- turning fit score into approval probability
