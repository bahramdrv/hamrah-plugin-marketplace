# Academic Supervisor Leads

For general supervisor discovery, read `academic_discovery_workflow.md` first and use its common discovery, signed current-affiliation/research verification and Persian report tools. Use this reference for additional former Iranian-student evidence and for the older shortlist contract. Its renderer is a compatibility fallback when the common tools are unavailable or when explicitly replaying that older contract; an API name never establishes current affiliation or recruitment.

Use this path only when the user explicitly asks for professors or research groups to contact. A complete immigration intake is optional. Establish country, research field and topic; collect only missing facts that would materially change this search. Call `discoverAcademicSupervisorCandidates` once with the ISO alpha-2 country code, public field, and topic; send no applicant facts. It searches bounded anonymous OpenAlex and ROR data and reads/writes expiring candidate names in shared Redis when configured. Each name, including one reused from the cache, is only a Supervisor Discovery Candidate. Search current official university or research-institution profiles and group pages for this request before showing a name. A directory listing alone is a lead to inspect, not research evidence. Use the user's words as search terms only; compare personal academic facts inside Hamrah. If the API or cache is unavailable, report the gap and continue a bounded official web search in the same country and field.

For each candidate, verify the named professor or group, institution, research topic, profile URL and current official research excerpt. Record the check date. Aim for three to five results within the requested scope and give the actual number if fewer qualify. Do not silently expand country or field. Where an official page publishes a contact channel, link that page. Never construct an address from a name or domain.

Check student recruitment separately. Use `explicitly_accepting` or `explicitly_not_accepting` only when a current official page explicitly states that status for doctoral or graduate students. Otherwise use `unknown`. A current research project, publication, grant, or lab member list does not imply recruitment. If the user requested only accepting professors, omit unknown and not-accepting candidates and describe the resulting coverage.

When the user also asks whether the professor or group previously had an Iranian student, search this evidence only for leads whose current official institutional page has been verified, within the bounded review. Seek public institutional evidence that explicitly ties a former student to this supervisor or group **and** explicitly connects that person to Iran. The same source excerpt should substantiate both links; inspect the full source context before using it. Use `documented` only for that evidence, otherwise `unknown`. Names, appearance, language, and inferred origin do not establish the connection. In ordinary results, omit the former student's name and cite the reviewed source URL. A documented former student says nothing about present recruitment, admissions or treatment of Iranian applicants.

Call `renderAcademicSupervisorShortlist` with only public facts, checked scope, coverage, and up to five leads. The renderer checks structure and caller-supplied excerpts; verify the live official pages before the call. Do not send applicant identity, profile, private fit reasons, or gaps. Preserve its complete primary Markdown text in the answer. Add brief private, source-linked research-fit notes from supplied academic facts when useful, while keeping speculative fit clearly labelled. Give one concrete next action, such as checking the professor's current group page before drafting a tailored contact message. Do not send a message without the user's explicit authorization.

An Academic Supervisor Lead is not an Academic Program Match or Verified Open Academic Opportunity. Do not imply an admission chance, funded opening, visa outcome, or present willingness to supervise from the lead alone. If live official pages cannot be checked, report the missing research requirement instead of using stale or invented results.
