# بررسی گسترش منابع دانشگاهی — ۲۰۲۶-۱۰-۰۱

این سند بررسی اولیه است، نه فهرست APIهای تازه فعال‌شده. عدد مشخصی برای رسیدن به پوشش کامل جهان وجود ندارد. واحد سنجش پوشش، ناشر × کشور × نوع موقعیت × محدودهٔ دریافت‌شده × تاریخ بررسی است؛ تعداد APIها فقط هزینهٔ اتصال را توصیف می‌کند.

## شمارش کار بعدی

کد فعلی هفت خانوادهٔ منبع دارد: DAAD، Studyinfo، Jobbnorge، Greenhouse، Lever، Ashby و SmartRecruiters. همگی به بازبینی شرایط persistence نیاز دارند؛ این‌ها هفت API جدید نیستند. بوردهای فعلی چهار Greenhouse، سه Lever پیش‌فرض، یک Ashby و چهار SmartRecruiters هستند؛ با DAAD، Studyinfo و NTNU، پانزده محدودهٔ ثابت ناشر/منبع داریم. بوردهای Lever که کاربر می‌دهد جدا هستند. این تعداد به معنی پانزده کشور یا پوشش ملی نیست.

برای دور بعد، سه API تازهٔ اولویت‌دار، یک API ذخیرهٔ کم‌اولویت و سه منبع وب/خوراک بررسی می‌شوند. این حجم کاری پیشنهادی برای افزایش پوشش است، نه عدد لازم برای پوشش کامل.

سه API اول عمدتاً خلأ استخدام پژوهشی/دکتری شغلی/پسادکترا را هدف می‌گیرند. آن‌ها شکاف مستر و دکتری پذیرشی و بورس را پر نمی‌کنند. آن بخش همچنان به سامانه‌های پذیرش ملی، فراخوان رسمی دانشگاه‌ها و جستجوی وب وابسته است. Grants.gov در بررسی اولیه از فهرست اولویت کنار گذاشته شد چون گرنت پروژه را نباید بورس فردی یا موقعیت استخدامی تلقی کرد.

## معیار انتخاب بعدی

منبع فقط زمانی متصل شود که هزینهٔ صفر و توقف در انتهای سهمیه، مبنای نگهداری، هویت ناشر، URL دقیق رسمی، country/category mapping و حد حجم/صفحه‌بندی روشن باشند. هر اتصال یک replay واقعی و تست executeTool برای خطا/سهمیه/انقضا دارد. اضافه‌شدن API به معنی اضافه‌شدن Verified Open Academic Opportunity نیست؛ صفحهٔ رسمی در درخواست جاری بررسی می‌شود.

برای سنجش پیشرفت، ماتریس کشور/نوع موقعیت با چهار حالت `API ناشر مشخص`، `وب بررسی‌شده`، `شکست/سهمیه` و `بررسی‌نشده` ثبت شود. «پوشش کامل» فقط می‌تواند به معنای کامل‌بودن محدودهٔ مشخص یک ناشر در یک زمان باشد؛ حتی آن هم با pagination یا محدودیت بودجه باید partial شود. برای جهان denominator معتبر از همهٔ آگهی‌ها نداریم و درصد پوشش نمی‌سازیم.

پس از درخواست مالک برای بررسی مستقیم، plan واقعی از مرورگر Vercel/Upstash تأیید شد: Free با ۵۰۰ هزار فرمان ماهانه، ۲۵۶ MB فضا و هزینهٔ جاری صفر. جزئیات در سند مخزن مشترک ثبت شد. Auto-upgrade کلید قابل مشاهده نداشت و خاموش‌بودن آن مستقلاً اثبات نشده؛ runtime، هزینه و تنظیم حساب تغییر نکرده‌اند.

پیشرفت اتصال: برش پسادکترای JobTech سوئد در کد محلی افزوده شد و درخواست واقعی `geochemistry/postdoc/SE` بدون کلید یک سرنخ Luleå با شناسهٔ 31501673 و مهلت 2026-10-12 برگرداند. مجوز CC0 آگهی‌های Platsbanken و رایگان‌بودن API از فهرست/راهنمای رسمی تأیید شد. persistence هنوز فعال نیست. از سه API اولویت‌دار، France Travail و NAV دو API بعدی‌اند؛ بررسی retention هفت خانوادهٔ قبلی همچنان جدا باقی است.
