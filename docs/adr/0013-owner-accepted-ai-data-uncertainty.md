# Record owner acceptance of unresolved AI data handling separately from provider evidence

On 20 October 2026 the owner explicitly instructed us to proceed without waiting for the outstanding Arvan processing and retention answers, after those unknowns had been presented. For the minimum one-answer projection in ADR-0011, we accept this as an operator decision to use the configured gateway with unresolved processing location, upstream recipient and content-retention details; it is recorded as `owner_accepted_unknowns`, dated, scoped to the fixed model/contract and fingerprint, and disclosed before the user submits text. This trades waiting for provider confirmation for bounded operation without claiming that the unknown facts became verified; structured answers, user confirmation, privacy filtering, deletion, expiry and the existing shared financial cap remain mandatory.
