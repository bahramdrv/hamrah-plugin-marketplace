# Triage status vocabulary

Incoming reports use these local `Status` values in their issue files:

| Role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the report. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the specified work. |
| `ready-for-human` | `ready-for-human` | Human action is required. |
| `wontfix` | `wontfix` | The report will not be actioned. |

Implementation tickets use `done` when their acceptance criteria are complete.
