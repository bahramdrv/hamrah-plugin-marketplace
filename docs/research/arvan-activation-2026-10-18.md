# بررسی زندهٔ آروان برای تیکت ۰۵ — ۱۸ اکتبر ۲۰۲۶

مجوز این نوبت: مالک سقف «فعلاً ۵۰ هزار تومان» و بررسی خواندنی پنل خصوصی را تأیید کرد. این سقف برای مجموع آزمون مصنوعی و مصرف ماهانهٔ این مرحله است؛ دو بودجهٔ مستقل ساخته نشده‌اند. در واحد نمایش تعرفهٔ آروان، ۵۰۰٬۰۰۰ ریال ثبت شد (۱۰ ریال برای هر تومان؛ تبدیل واحد است، نه تبدیل ارز).

## شواهد پنل، بدون تغییر خدمات

- [مشخصات درگاه](https://panel.arvancloud.ir/aiaas/ai-gateway/kooch/details/overview): دامنهٔ `https://api.arvancloudai.ir` و Endpoint برابر `https://api.arvancloudai.ir/v1`؛ یک مدل از ۹۳ مدل متصل، بدون پایگاه دانش و گاردریل. متن پنل، ساخت و نگهداری درگاه پیش‌فرض را رایگان و هزینه را تابع مصرف مدل و توکن‌ها معرفی می‌کند.
- [مدل متصل](https://panel.arvancloud.ir/aiaas/ai-gateway/kooch/details/models): `Qwen3.5-35B-A3B` فعال، مصرف ورودی/خروجی صفر؛ دو خانهٔ قیمت «ـ» هستند. این علامت به معنی رایگان پذیرفته نشد.
- [بازارچهٔ رسمی](https://panel.arvancloud.ir/aiaas/model/bazaar): برای همان مدل، Hosted by ArvanCloud و Beta، کانتکست ۴۰۰K؛ ورودی **۴٬۲۰۰٬۰۰۰ ریال / ۱م توکن** و خروجی **۴٬۲۰۰٬۰۰۰ ریال / ۱م توکن** درج شده‌اند. این شاهد نرخ نمایشی است، نه تأیید invoice، گردکردن نهایی یا کیفیت inference. شاهد در ۱۴:۰۵ UTC ثبت و در تنظیمات فقط ۲۴ ساعت معتبر است؛ دریافت تازه خودکار آن را تمدید نمی‌کند.
- [تنظیمات درگاه](https://panel.arvancloud.ir/aiaas/ai-gateway/kooch/details/settings): ۱ درخواست در بازهٔ ثابت ۵ دقیقه. گزینهٔ تضمین عدم retry یا routing جایگزین در این صفحه وجود نداشت؛ نبود گزینه، تضمین نبود رفتار پنهان نیست.
- [ماشین‌یوزرها](https://panel.arvancloud.ir/profile/iam/machine-users): `kooch-ai` با نام نمایشی Kooch AI Gateway فعال است. «مشاهده قوانین دسترسی متصل» برای همین ماشین‌یوزر، «موردی برای نمایش وجود ندارد» برگرداند. هیچ کلید دسترسی باز یا کپی نشد.
- [مدیریت منابع](https://panel.arvancloud.ir/profile/iam/resource-management): گروه `kooch-ai-only` شامل `kooch-Qwen3-5-35B-A3B-61689` است. پیش‌نمایش قانون دسترسی برای همان منبع، نقش قابل انتخاب نداشت. پیش‌نمایش گروه نقش‌هایی از IAM و DNS نشان داد، ولی جست‌وجوی «هوش» و «AI» هر دو «موردی وجود ندارد» دادند. فرم‌ها با انصراف بسته شدند؛ قانون جدیدی ثبت نشد.

## مانع پذیرش و سؤال‌های آماده برای پیگیری

این بررسی محدودبودن دسترسی کلید را اثبات نکرد؛ نبود قانون متصل حتی در کنار GET موفق قبلی مدل‌ها برای نتیجه‌گیری دربارهٔ مجوز inference کافی نیست. گسترش دسترسی به کل میزکار، انتخاب مدل دیگر و ساخت ماشین‌یوزر/کلید/درگاه تازه انجام نشدند. هیچ درخواست تولید پاسخ یا هزینه‌ای در این نوبت اجرا نشد.

برای رفع مانع، پاسخ رسمی سرویس به این موارد لازم است:

1. برای AI Gateway فعلی، نقش فراخوانی مدل چگونه فقط به منبع/گروه بالا و ماشین‌یوزر موجود محدود می‌شود؟ چرا انتخاب‌گر نقش منبع خالی است و گروه، نقش AI ندارد؟
2. هدر دقیق Chat Completions همین gateway چیست؟ آیا raw HTTP باید `Authorization: apikey …` باشد یا قالب نمونهٔ SDK متفاوت است؟
3. آیا درگاه retry یا fallback upstream دارد و چگونه برای این منبع خاموش/محدود می‌شود؟
4. آیا سقف `max_tokens=128` شامل reasoning و همهٔ خروجی صورتحساب است؟ آیا usage کامل و شناسهٔ مدل گزارش می‌شوند؟ JSON Schema چه قراردادی دارد؟
5. آیا تعرفهٔ بازارچه برای همین مدل روی همین درگاه اعمال می‌شود؛ شیوهٔ گردکردن، هزینهٔ خطا، مالیات/هزینهٔ افزوده و نسخهٔ تعرفه چیست؟

این متن آمادهٔ پیگیری است؛ پیامی به پشتیبانی ارسال نشده است. پس از رفع این موارد، آزمون مصنوعی محدود از سرور انتشار باید latency، usage، فارسی، refusal/JSON و تاریخ پذیرش را ثبت کند. تا آن زمان fingerprint، هدر، IAM و پذیرش task در تنظیمات خالی/false می‌مانند.
