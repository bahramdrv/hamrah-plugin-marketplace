# پایش منابع مسیرها در چرخهٔ ۳۰روزه

## دامنه و نتیجه

کراولر به‌جای اطلاعات افراد، منابع عمومیِ فهرست مسیرها، شروط پذیرفته‌شده، کانال درخواست و پورتال‌های مقصدها را دریافت می‌کند. منابع لینک‌شده توسط Visa Atlas با عنوان `atlas_link_unreviewed` از منابعی که قبلاً گزاره‌ای از آن‌ها بررسی شده (`published_primary`) جدا هستند. دریافت موفق، اعتبار حقوقی، جامعیت شروط، شمول ایرانی یا صلاحیت متقاضی را ثابت نمی‌کند.

Visa Atlas هم API خلاصه و هم راهنماهای HTML مفصل‌تر دارد. API مسیرها ۱۴۱۴ رکورد دارد، اما این عدد تعداد بسته‌های کاملِ شروط نیست. API حقوق ۶۲ رکورد در ۲۱ مقصد و API تغییرات ۱۶۰ گزارهٔ سیاستی دارد؛ هرکدام دامنه و تاریخ خود را دارند. متن راهنمای کارت فرصت آلمان از خلاصهٔ API جزئیات بیشتری دارد. [قرارداد عمومی Atlas](https://visaatlas.org/api)، [نمونهٔ راهنمای مفصل](https://visaatlas.org/visas/germany/chancenkarte). بنابراین استفادهٔ قبلیِ ما از خلاصهٔ مسیرها نیز بخشی از کمبود را ایجاد کرده بود؛ Atlas جای تأیید مرجع صادرکننده را نمی‌گیرد.

## زمان‌بندی و ماندگاری

Workflow `crawl-kooch-official-sources.yml` هر روز ساعت ۰۷:۵۳ تهران فعال می‌شود، اما فقط منابع سررسیدشده را دریافت می‌کند. فاصلهٔ دریافت‌های موفق برای هر URL سی روز کامل است، نه روز اول هر ماه؛ خطاها پس از یک روز دوباره امتحان می‌شوند. GitHub ممکن است اجرای زمان‌بندی را با تأخیر انجام دهد.

وضعیت عمومی و تاریخچهٔ خلاصه روی شاخهٔ مستقل `kooch-crawl-state` در همین مخزن می‌ماند. HTML، PDF کامل، توکن، اطلاعات حساب یا دادهٔ متقاضی منتشر نمی‌شود. شاخهٔ main توسط کراولر تغییر نمی‌کند؛ فایل تنظیمات شاخهٔ داده، استقرار خودکار آن را خاموش می‌کند. artifact هفت‌روزه برای عیب‌یابی است و جای وضعیت پایدار شاخه را نمی‌گیرد. هیچ سرویس پولی یا کلید تازه لازم نیست.

## دریافت و تغییرات

فقط HTTPS عمومی، بررسی IP و TLS، اتصال به همان IP بررسی‌شده با نام صحیح TLS، حداکثر ۲MB، مهلت و همزمانی محدود استفاده می‌شود. robots.txt رعایت می‌شود؛ خطای robots یا challenge، دریافت موفق محسوب نمی‌شود. تغییر مسیر فقط در همان میزبان یا گونهٔ www مجاز است؛ مقصد دیگر نیازمند بررسی است. robots مقصد جدید پیش از دریافت کنترل می‌شود.

hash بدنه و hash متنِ بخش main/article جدا هستند. تغییر منو یا footer به‌تنهایی تغییر حقوقی اعلام نمی‌شود. تغییر متن هم فقط نشانهٔ بازبینی است، نه تأیید تغییر قانون. PDF با hash بدنه ردیابی می‌شود و استخراج شرط از آن خودکار نیست. حداکثر پنج سرنخ بیست‌کلمه‌ای زیر تیتر شروط و سی لینک اکتشافی ثبت می‌شود؛ همه `unreviewed` هستند. لینک اکتشافی خودکار به منبع رسمی یا مسیر تازه تبدیل نمی‌شود.

## اثر در محصول و بازبینی

`public-status.json` با قرارداد محدود و نشانی ثابت در برنامه خوانده می‌شود. مسیر دارای بازبینی باز، در مرور کاتالوگ و غربال فردی نتیجهٔ مثبت جاری نمی‌گیرد؛ گزارش ذخیره‌شدهٔ تاریخی بازنویسی نمی‌شود. تغییر پورتال عمومی به‌تنهایی همهٔ مسیرهای کشور را مسدود نمی‌کند. در دسترس نبودن منبع به معنی بسته‌شدن مسیر نیست. تاریخ `checked_on` شروط توسط کراولر تغییر نمی‌کند؛ اعتبار حقوقی موجود مستقل از چرخهٔ دریافت باقی می‌ماند.

بازبینی در `apps/kooch/data/source-crawl-reviews.json` با کلید URL و مقدار `{ "semantic_sha256": "...", "reviewed_on": "YYYY-MM-DD", "review_reference": "commit-or-document-reference" }` ثبت می‌شود. فقط hash دقیق، تاریخ پس از capture و ارجاعِ بازبینی، صف همان منبع را می‌بندد. این اقرار خودکار شروط دادهٔ اصلی را به‌روز نمی‌کند؛ تغییر حقوقی باید در نسخهٔ جدید رجیستری همراه آزمون مستقل ثبت شود. تغییر بعدی دوباره صف را باز می‌کند.

برای نشانی خراب یا کنارگذاشته‌شده، همین بازبینی می‌تواند `replaced_by_urls` داشته باشد. هر جانشین باید در فهرست دریافت موجود، منبع primary منتشرشده، دریافت موفق و پوشش‌دهندهٔ شناسه‌های مسیر قبلی باشد؛ تاریخ بازبینی نیز باید پس از دریافت‌ها باشد. منبع صرفاً منتسب به دولت در Atlas کافی نیست. خودکار جانشین انتخاب نمی‌شود. تاریخچه، خطای HTTP و hash نشانی قدیمی حفظ می‌شوند؛ دریافت آن پس از پذیرش جانشین متوقف می‌شود. بازبینیِ لغوشده، جانشین ناموفق یا جانشینِ نیازمند بازنشستگی، صف را دوباره باز می‌کند. نشانی‌های کنارگذاشته‌شده در شمار منابع ناموفق باقی می‌مانند و بسته‌شدن مسیر از آن‌ها استنباط نمی‌شود.

## اجرای محلی

```bash
python3 apps/kooch/scripts/source_crawler_test.py
python3 apps/kooch/scripts/source_crawler.py --output /tmp/kooch-crawl
python3 apps/kooch/scripts/source_crawler.py --previous /tmp/kooch-crawl/state.json --output /tmp/kooch-crawl-next
```

برای smoke محدود می‌توان `--max-sources 5` داد؛ چنین اجرا پوشش کل ندارد. وضعیت خراب یا دارای تاریخ آینده پذیرفته نمی‌شود و اجرای ناقص منتشر نمی‌شود. حذف یک منبع از فهرست قبلی، نیازمند بازبینی می‌ماند و معادل بسته‌شدن برنامه نیست.
