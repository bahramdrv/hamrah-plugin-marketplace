# بررسی API دانشگاهی بین‌المللی — ۲۰۲۶-۱۰-۰۱

هدف: آگهی جاری دکتری، پسادکتری و کار پژوهشی دانشگاه‌ها در چند کشور؛ فهرست نام دانشگاه‌ها، دادهٔ مقاله و فرصت تاریخی جای این داده را نمی‌گیرد. JSearch مناسب‌ترین API عمومیِ چندکشوری با سهمیهٔ رایگانِ تکرارشونده است؛ کیفیت و گسترهٔ آگهی‌های دانشگاهی آن باید بعد از دریافت کلید با درخواست واقعی سنجیده شود.

پس از آزمون feed تخصصی، **اتصال اول پیشنهادی AcademicJobsOnline است**: رایگان، بدون کلید و دارای دادهٔ واقعیِ دانشگاهی چندکشوری. نوع فنی آن RSS/XML است؛ آن را API جستجوی JSON معرفی نمی‌کنیم. JSearch گزینهٔ بعدی برای گسترهٔ بیشتر کشورهاست.

## انتخاب API: JSearch با کلید Free

[صفحهٔ رسمی JSearch](https://www.openwebninja.com/api/jsearch) طرح Free با ۲۰۰ درخواست ماهانه، Hard Limit و بدون کارت اعتباری و پوشش جستجوی چندکشوری Google for Jobs معرفی می‌کند. دادهٔ JSON شامل عنوان، کارفرما، کشور و لینک درخواست است؛ API تخصصی دانشگاه‌ها نیست و تعداد دانشگاه‌های حاضر مشخص نیست. [شرایط رسمی](https://www.openwebninja.com/terms) بخش API Data اجازهٔ استفاده در محصول گسترده‌تر را می‌دهد؛ بازفروش به‌شکل API مستقل مجاز نیست. این اتصال فعلاً request-scoped و بدون ذخیرهٔ آگهی پیشنهاد می‌شود.

کاربر از Try for free در صفحهٔ رسمی وارد حساب OpenWeb Ninja شود، طرح **Free** را انتخاب و کلید دریافت کند؛ کارت وارد نکند و طرح پولی انتخاب نکند. کلید باید در محیط اجرا به‌صورت محرمانه تنظیم شود، نه در کد، سند یا پیام عادی. اثبات اتصال واقعی و کیفیت آگهی دانشگاهی به دریافت کلید وابسته است؛ سهمیهٔ رایگان به معنی پوشش همهٔ کشورها در هر درخواست نیست.

## جایگزین بدون کلید: AcademicJobsOnline RSS

[صفحهٔ رسمی آگهی‌ها](https://academicjobsonline.org/ajo/jobs) به [feed رسمی](https://academicjobsonline.org/ajo?joblist-0-0-0-----rss--) لینک دارد. آزمون عمومی HTTP 200، RSS 1.0 با gzip و ۳۱۷ آگهی، حجم بازشدهٔ ۱۷۳۷۹۲۷ بایت و آگهی تازهٔ ۳۰ سپتامبر داشت. فیلدهای اختصاصی Country، Deadline، Univ، Disciplines، ID و EndDate وجود دارند؛ EndDate پایان نمایش آگهی است و جای deadline نیست، deadline بعضی موارد خالی است. بدنهٔ کامل ممکن است اطلاعات تماس داشته باشد و نباید ذخیره شود. این feed با ثبت‌نام یا کلید وابسته نیست و واقعاً آگهی دانشگاهی دارد؛ API جستجوی JSON نیست و تنها مؤسسات مشارکت‌کننده را پوشش می‌دهد. [صفحهٔ اصلی](https://academicjobsonline.org/) عمومی‌بودن آگهی بدون کوکی را تأیید می‌کند، اما حق کش مستقل یا بازنشر کامل آگهی را صریحاً نمی‌دهد؛ استفادهٔ محدود از سرنخ لینک‌شده و بررسی اصلی مناسب‌تر است.

[Mathjobs](https://www.mathjobs.org/jobs) نیز feed رسمی https://www.mathjobs.org/jobs?joblst------rss دارد: آزمون HTTP 200 و ۳۰۲ آگهی RSS با حجم بازشدهٔ ۱۵۵۳۵۶۶ بایت. [راهنمای رسمی](https://www.mathjobs.org/help/mathjobs/link/app-jobs.html) feed را برای خواننده یا صفحهٔ شخصی توضیح می‌دهد؛ دامنهٔ تخصصی ریاضی دارد. API ذکرشده در homepage برای همگام‌سازی خصوصی استخدام/ارسال آگهی دانشگاه است، نه API عمومی دریافت.

در snapshot آزمون AcademicJobsOnline، ۱۰۱ مقدار متمایز Univ و ۲۰ کد کشور وجود داشت؛ بعضی کارفرماها مؤسسهٔ پژوهشی‌اند، پس آن را «۱۰۱ دانشگاه» نمی‌نامیم. توزیع: US 251، CA 12، QA 8، CN 7، TW 6، DK 5، DE 4، NL/FR/JP/VN هرکدام 3، CH/GB/IL هرکدام 2 و PL/HK/SG/IN/KR/SA هرکدام 1. غلبهٔ آمریکا واضح است. ۸۹ آگهی deadline خالی داشت؛ تعداد مذکور شمار آگهی‌های دریافت‌شده پیش از حذف منقضی/نامرتبط است و شمار فرصت بازِ تأییدشده نیست.

[راهنمای رسمی ساخت آگهی](https://academicjobsonline.org/help/academicjobs/userdoc/link/newjob.html) زمان نمایش from/to را از deadline جدا می‌کند: کارفرما می‌تواند نمایش را پس از deadline تمدید کند و همچنان دریافت درخواست را ببندد؛ آگهی withdrawn نیز ممکن است در فهرست عمومی بماند. بنابراین EndDate یا حضور در feed به معنی پذیرش درخواست نیست. feed فیلد native نوع موقعیت یا وضعیت پذیرش ندارد؛ دسته‌بندی عنوان باید محدود و شفاف باشد و تأیید بازبودن از صفحهٔ اصلی در همان درخواست انجام شود.

## EURAXESS: بهترین تناسب موضوعی، اما API خواندن تأیید نشده

[صفحهٔ رسمی فرصت‌ها](https://euraxess.ec.europa.eu/jobs) می‌گوید هزاران فرصت از بیش از ۴۳ کشور و مناطق دیگر منتشر می‌کند. [جستجوی رسمی](https://euraxess.ec.europa.eu/jobs/search) کشور، رشته و نوع فرصت را تفکیک می‌کند. این تعداد کشور تضمین پوشش تمام دانشگاه‌ها نیست.

[راهنمای XML رسمی](https://euraxess.ec.europa.eu/api/xmlguidelines) برای ارسال آگهی توسط سازمان‌هاست؛ API دریافت یا جستجوی آگهی برای ما نیست. ثبت‌نام سازمانی و organisationID آن را نباید کلید دریافت داده معرفی کرد.

آزمایش خواندن عمومی [job-feed](https://euraxess.ec.europa.eu/job-feed) در این تاریخ پاسخ HTTP 200 با application/rss+xml، حجم ۱۱۸۹۱ بایت و ۲۰ item داشت؛ بدون کلید. خود description کانال می‌گوید فقط آگهی‌های اخیر را می‌آورد و برای فهرست کامل باید به سایت رفت. فیلدهای موجود عنوان، لینک، خلاصه، تاریخ انتشار، سازمان و شناسه‌اند؛ کشور و deadline ساختاریافته ندارد. نمونه‌های مشاهده‌شده مربوط به ۱۶ سپتامبر بودند، درحالی‌که جستجوی سایت آگهی‌های ۲۸ سپتامبر داشت: تازه‌بودن feed هنوز قابل اتکا نیست. این مشاهدهٔ نمونه است، نه اثبات خرابی همهٔ feed.

[robots.txt رسمی](https://euraxess.ec.europa.eu/robots.txt) هنگام آزمون API/rest، URLهای queryدار و /jobs/* را منع می‌کرد؛ /jobs را مجاز کرده است. endpoint حدسی Drupal یا API داخلی را اتصال رسمی معرفی نمی‌کنیم. feed محدود می‌تواند فقط سرنخ عمومی باشد؛ جای جستجوی جاری و بررسی صفحهٔ اصلی دانشگاه را نمی‌گیرد. مجوز ذخیره‌سازی آگهی‌های نوشته‌شده توسط اشخاص ثالث مستقلاً تأیید نشده؛ سیاست کلی کپی‌رایت اتحادیه فقط محتوای تحت مالکیت اتحادیه را خودکار پوشش می‌دهد.

## Adzuna: API واقعی چندکشوری، رایگان‌بودن مشروط به کاربرد

[API رسمی](https://developer.adzuna.com/overview) app_id و app_key و endpoint جستجوی آگهی دارد. [بازاریابی رسمی](https://www.adzuna.com/hire/products/job-listings/) از ۱۹ کشور سخن می‌گوید؛ تعداد دانشگاه‌های حاضر و پوشش موقعیت‌های دانشگاهی منتشر نشده است.

[شرایط رسمی API](https://developer.adzuna.com/docs/terms_of_service): سهمیهٔ پیش‌فرض ۲۵ در دقیقه، ۲۵۰ روزانه، ۱۰۰۰ هفتگی و ۲۵۰۰ ماهانه. انتشار آگهی، تخمین حقوق و پژوهش شخصی کاربردهای مجازند؛ کاربرد دیگر تجاری/دولتی/دانشگاهی پس از آزمون ۱۴روزه نیازمند رضایت کتبی است و ممکن است قرارداد بخواهد. نمایش آگهی الزام نام و نشان Jobs by Adzuna دارد. با خاتمهٔ دسترسی حذف داده الزامی است. نمایش request-scoped خودِ آگهی با نشان الزامی ممکن است داخل کاربرد مجاز انتشار قرار گیرد؛ این استنباط است، نه رد یا قبول قطعی برای خروجی سرنخ پژوهشی Hamrah. مدت TTL کش مشخص نشده است؛ کاربرد و نمایش دقیق باید روشن شود.

اگر توافق مناسب فراهم شد: [ثبت‌نام توسعه‌دهنده](https://developer.adzuna.com/signup)، درج ایمیل و نام/وب‌سایت سازمان و کاربرد، سپس دریافت app_id و app_key طبق overview. فعلاً برای این گزینه درخواست کلید نمی‌کنیم.

## Careerjet: گسترده‌تر، اما نیازمند بررسی تناسب و دادهٔ کاربر

[API رسمی v4](https://www.careerjet.com/partners/api) جستجوی آگهی با locale کشور، واژه، صفحه و ۱۰۰ نتیجه دارد. کلید به هر سایت ناشر تعلق دارد؛ Basic auth با کلید و رمز خالی. [صفحهٔ ناشران](https://www.careerjet.com/partners/publishers) API را برای نمایش نتایج روی وب‌سایت معرفی می‌کند، نه گردآوری بانک دادهٔ مستقل. این صفحه قیمت/سهمیهٔ رایگان قطعی و حق کش را مشخص نمی‌کند؛ ادعای رایگان بودن فهرست‌های ثالث کافی نیست.

user_ip و user_agent واقعیِ کاربری که جستجو را آغاز کرده الزامی است. در معماری فعلی MCP نباید IP ساختگی یا IP سرور را جای آن بفرستیم. اتصال فقط با سازگاری واقعی این الزام و روشن‌شدن شرایط ناشر قابل توصیه است. داده عمومی مشاغل است و آمار پوشش دانشگاهی ندارد.

مسیر کاربر در صورت انتخاب: صفحهٔ ناشران → Sign up now → [حساب ناشر](https://www.careerjet.com/register?redir=/partners/register/as-publisher)، ثبت وب‌سایت در Publisher account و دریافت کلید مختص همان سایت طبق مستندات API. پس از ورود باید شرایط حساب/قیمت/حق نمایش و کش دوباره بررسی شود. حسابی ایجاد نشده و کلیدی گرفته نشده است.

## نتیجهٔ اجرایی

JSearch بهترین مسیر API چندکشوریِ قابل آزمون با کلید رایگان است؛ AcademicJobsOnline قوی‌ترین feed تخصصیِ بدون کلید در این بررسی است. EURAXESS مسیر بین‌المللی دانشگاهی برای بررسی وب است، ولی feed آن بسیار محدود است. Adzuna و Careerjet برای وعدهٔ اتصال رایگان پایدار و مناسب Hamrah شروط حل‌نشده دارند. هیچ‌کدام پوشش جهانی کامل را ثابت نمی‌کند.
